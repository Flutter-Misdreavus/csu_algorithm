区间DP
第i个珠子的头为 conme[i] 尾为 conme[i + 1]
要复制一遍代表循环， conme[2n+1] = conme[1];
dp[i][j] 代表i-j号珠子能产生的最大能量
从后往前
j-k, k+1 - i合并时释放 conme[j] * conme[k + 1] * conme[i]

```
	for(int i = 2; i <= 2*n; i++){
		for(int j = i - 1; j >= 1 && i - j < n; j--){
			for(int k = j; k < i; k++){
				dp[j][i] = max(dp[j][i], dp[j][k] + dp[k + 1][i] + conme[j] * conme[k + 1] * conme[i + 1]);
			}
		}
	}
```
