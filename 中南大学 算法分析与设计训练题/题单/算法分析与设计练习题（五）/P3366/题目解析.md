# 【模板】最小生成树

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P3366

知识点：最小生成树、并查集、Kruskal算法

## 题目简述

> 给定一个含 N 个节点和 M 条边的无向图，求该图的最小生成树（Minimum Spanning Tree，MST）。若图不连通则输出 `orz`。
>
> 数据范围：1 ≤ N ≤ 5000，1 ≤ M ≤ 2 × 10^5，边权 1 ≤ Z_i ≤ 10^4
>
> 时间限制：1S，空间限制：125MB

## 题目分析

### 详细版

1. **读题**：本题要求求解无向图的最小生成树。最小生成树是指在一个带权无向图中，选取恰好 N-1 条边使得所有节点连通，且总权值最小。如果无法连通所有节点（即不存在生成树），则输出 `orz`。

2. **性质观察**：本题可以使用经典的三种最小生成树算法求解：Kruskal 算法、Prim 算法或 Boruvka 算法。其中 Kruskal 算法思路简洁，适合本题的数据规模。

3. **程序设计**：
   - 读取 N 和 M
   - 读取 M 条边的信息（起点、终点、权值），存入边集合
   - 将所有边按权值升序排序
   - 依次遍历排序后的边，使用并查集检查边的两端是否已在同一连通分量中
   - 若不在，则选择该边加入最小生成树，并将两节点合并
   - 选取足够 N-1 条边后，输出总权值；若无法选够 N-1 条边，输出 `orz`

4. **数据结构与算法选择**：
   - 使用并查集（Union-Find）实现 Kruskal 算法
   - 并查集支持路径压缩和按秩合并优化
   - 对边按权值排序：时间复杂度 O(M log M)

5. **时空复杂度分析**：
   - 时间复杂度：O(M log M) （排序） + O(M α(N)) （并查集操作，α 为 Ackermann 函数的反函数）
   - 空间复杂度：O(N + M) （并查集 + 边数组）

### 省流版

使用 Kruskal 算法求解最小生成树：将 M 条边按权值升序排序，依次选择不构成环的边加入生成树，若最终选够 N-1 条边则输出总权值，否则输出 `orz`。

## 代码实现

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <queue>
#include <algorithm>
#include <vector>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int bingchaji[5010];
vector<pair<pair<int, int>, int>> bian; //起点 终点 长度

void add_bing(int a, int b){
    // 将a,b合并到一个并查集里
    int s = bingchaji[b];

    while(s != bingchaji[s]){
        s = bingchaji[s];
    }

    bingchaji[s] = a;

    return;
}

int is_bing(int a, int b){
    int s1 = bingchaji[a];
    int s2 = bingchaji[b];

    while (s1 != bingchaji[s1]){
        s1 = bingchaji[s1];
    }
    while(s2 != bingchaji[s2]){
        s2 = bingchaji[s2];
    }

    bingchaji[a] = s1;
    bingchaji[b] = s2;

    if(s1 == s2){
        return 1;
    }else{
        return 0;
    }
    
    return 0;
}

int main(){
    int n, m;
    int a, b ,c;
    int chang = 0;

    scanf("%d%d", &n, &m);
    for(int i = 0; i < m; i++){
        scanf("%d%d%d", &a, &b, &c);
        bian.push_back({{a, b}, c});
    }
    for(int i = 1; i <= n; i++){
        bingchaji[i] = i;
    }

    sort(bian.begin(), bian.end(), [](auto &a, auto &b){
        return a.second < b.second;
    });


    int flag = 0; //已经选取的边的数量，小于等于n-1
    for(auto it = bian.begin(); it != bian.end() && flag < n; it++){
        a = (*it).first.first;
        b = (*it).first.second;
        c = (*it).second;

        if(!is_bing(a, b)){
            flag++;
            chang += c;
            add_bing(a, b);
        }
    }

    if(flag == n - 1){
        printf("%d\n", chang);
    }else{
        printf("orz\n");
    }
}
```
