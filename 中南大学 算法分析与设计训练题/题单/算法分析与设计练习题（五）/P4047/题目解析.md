# P4047 [JSOI2010] 部落划分

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P4047

知识点：并查集、最小生成树、Kruskal

## 题目简述

> 有 n 个野人居住点，给每个点分配一个部落标签，要求恰好划分为 k 个部落。定义两个部落的距离为两部落中距离最近的两点间距离。求一种划分方式，使得最近的两个部落距离尽可能大，输出这个最大距离。
>
> 数据范围：2 ≤ k ≤ n ≤ 10³，0 ≤ x, y ≤ 10⁴
>
> 时间限制：1S，空间限制：128MB

## 题目分析

### 详细版

1. **读题**：n 个平面点，需要划分为恰好 k 个部落。目标是最小化"最近两个部落的距离"中的最大值——即最大化最近部落间距离的下界。

2. **性质观察**：本题等价于求最小生成树（MST）。将所有 n 个点看作图的顶点，任意两点间边的权值为欧氏距离。当我们用 Kruskal 算法构造 MST 时，依次加入最短的边并合并连通块，直到只剩 k 个连通块。此时最后加入的那条边的权值即为答案——因为这保证了剩下的 k 个部落之间两两距离都 ≥ 该值，且该值是能达到的最大下界。

3. **程序设计**：
   - 预处理所有点对距离，共 n(n-1)/2 条边
   - 使用并查集维护部落划分
   - 依次合并距离最近的两个部落（类似 Kruskal）
   - 合并 n-k 次后，答案为当前最小部落间距离

4. **数据结构与算法选择**：
   - 并查集：高效合并与查询部落归属
   - 边表：存储所有点对距离（稠密图用邻接矩阵更简洁）
   - Kruskal 思想：每次找最小边合并，直到剩 k 个集合

5. **时空复杂度分析**：
   - 时间：O(n²) 建图 + O(n²) 合并过程 = O(n²)，n≤1000 可行
   - 空间：O(n²) 距离矩阵

### 省流版

将 n 个点用并查集不断合并成 k 个部落，每次合并距离最近的两个部落。合并 n-k 次后，当前最小的部落间距离即为答案。本质是 Kruskal 构造最小生成树到只剩 k 条边。

## 代码实现

![AC截图](./P4047AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>
#include <vector>
#include <stack>
#include <queue>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int bingchaji[1010];
double dist[1010][1010];
int px[1010];
int py[1010];

void init(int n){
    for(int i = 0; i < n; i++){
        bingchaji[i] = i;
    }
}

int find(int a){
    int s = bingchaji[a];
    while(s != bingchaji[s]){
        s = bingchaji[s];
    }
    bingchaji[a] = s;
    return s;
}

void memgre(int a, int b){
    bingchaji[b] = find(a);
}

// 找到距离最近的两个部落（属于不同部落）
void find_min(int n, int* a, int* b){
    double mind = 10e6;
    for(int i = 0; i < n; i++){
        if(find(i) != i) continue;  // 只从代表元开始找
        for(int j = 0; j < n; j++){
            if(dist[i][j] == 0) continue;
            if(dist[i][j] < mind){
                mind = dist[i][j];
                *a = i;
                *b = j;
            }
        }
    }
    return;
}

// 找当前最小的部落间距离
double find_min_dist(int n){
    double mind = 10e6;
    for(int i = 0; i < n; i++){
        if(find(i) != i) continue;
        for(int j = 0; j < n; j++){
            if(dist[i][j] == 0) continue;
            if(dist[i][j] < mind){
                mind = dist[i][j];
            }
        }
    }
    return mind;
}

// 合并两个部落
void memgre_buluo(int n){
    int a, b;
    find_min(n, &a, &b);
    memgre(a, b);
    // 更新距离矩阵：合并后该部落到其他点的距离取较小值
    for(int i = 0; i < n; i++){
        if(dist[a][i] > dist[b][i]){
            dist[a][i] = dist[b][i];
            dist[i][a] = dist[a][i];
        }
    }
}

int main(){
    int n, k;
    scanf("%d%d", &n, &k);
    for(int i = 0; i < n; i++){
        scanf("%d%d", &px[i], &py[i]);
    }
    // 计算所有点对欧氏距离
    for(int i = 0; i < n; i++){
        for(int j = 0; j < n; j++){
            dist[i][j] = hypot(px[i] - px[j], py[i] - py[j]);
        }
    }

    init(n);
    // 合并 n-k 次，得到 k 个部落
    for(int i = 0; i < n - k; i++){
        memgre_buluo(n);
    }

    printf("%.2lf\n", find_min_dist(n));
    return 0;
}
```
