# T507571 色彩入侵

## 题目背景

>那一道自井中浮现的磷光不禁使人们产生一种异样的感觉，一种厄运降临的感觉。这种感觉已远超他们的意识所能构想的任何景象；那种色彩不再只是闪闪发光，而是自井口喷涌而出。
>当这股由无法辨认的色彩组成的无形洪流离开井口之时，它就仿佛直接流向了天空。
>&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;&emsp;——H.P.洛夫克拉夫特《来自群星的色彩》

*星之彩*是一种来自已知宇宙之外的，非完全物质的奇怪生命形式，具有无法用科学解释的属性。它似乎以各种有机生命为食，并会使猎物在身体和精神上发生变异和退化。当它吸取了足够的能量后，就会离开这颗行星、前往太空。

对人类彻底失望，身为降临派的您当然非常乐意亲眼见证星之彩毁灭人类的盛景，于是身为 ACM 大神的您打算写一个程序加速自己夙愿的实现，现在您遇到了这样一个问题：

## 题目描述

给定 $t$ 组数据，每组数据给定一长度为 $n$ 的整数列 $c_1\sim c_n$，代表有 $n$ 个物品排成一行，物品编号从 $1$ 到 $n$，第 $i$ 个物品的颜色为 $c_i$。

现在每次可将连续的 $k$ 个物品粉刷成任意颜色，请求得将所有物品刷成同一颜色所需最少的次数。

## 输入格式

第一行有一个正整数 $t(1 \le t \le {10}^4)$，代表数据组数。

对于每组数据，第一行有两个整数 $n, k(1 \le k \le n \le {10}^5)$，代表物品总数与每次可粉刷的物品数量。

第二行有 $n$ 个整数 $c_i(1 \le c_i \le 100)$，第 $i$  个整数代表第 $i$ 个物品初始的颜色 $c_i$。

保证对于所有组数据满足 $\sum n\le 10^5$。

## 输出格式

输出共 $t$ 行，每行为对应数据的答案。

## 输入输出样例 #1

### 输入 #1

```
3
10 2
1 1 2 2 1 1 2 2 2 1
7 1
1 2 3 4 5 6 7
10 3
1 3 3 3 3 1 2 1 3 3
```

### 输出 #1

```
3
6
2
```
