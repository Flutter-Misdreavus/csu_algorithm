# P2249 【深基13.例1】查找

## AC截图

![AC截图](P2249AC.png)

## 题目描述

输入 $n$ 个不超过 $10^9$ 的单调不减的（就是后面的数字不小于前面的数字）非负整数 $a_1,a_2,\dots,a_{n}$，然后进行 $m$ 次询问。对于每次询问，给出一个整数 $q$，要求输出这个数字在序列中第一次出现的编号，如果没有找到的话输出 $-1$ 。

## 输入格式

第一行 $2$ 个整数 $n$ 和 $m$，表示数字个数和询问次数。

第二行 $n$ 个整数，表示这些待查询的数字。

第三行 $m$ 个整数，表示询问这些数字的编号，从 $1$ 开始编号。

## 输出格式

输出一行，$m$ 个整数，以空格隔开，表示答案。

## 输入输出样例 #1

### 输入 #1

```
11 3
1 3 3 3 5 7 9 11 13 15 15
1 3 6
```

### 输出 #1

```
1 2 -1
```

## 说明/提示

数据保证，$1 \leq n \leq 10^6$，$0 \leq a_i,q \leq 10^9$，$1 \leq m \leq 10^5$

本题输入输出量较大，请使用较快的 IO 方式。

## 题目分析

### 问题本质

在一个**有序序列**中查找指定元素**第一次出现的位置**，这是经典的**二分查找（Binary Search）**问题。

### 关键点

1. **序列有序**：单调不减序列，可以使用二分查找
2. **找第一次出现**：存在重复元素时，需要找到最左边的那个
3. **高效查询**：$n$ 和 $m$ 都很大，暴力 $O(nm)$ 会超时

---

## 解题思路

### 方法一：手写二分查找

**核心思想**：利用序列有序性，每次将搜索范围缩小一半。

**找第一次出现的位置**的关键：当 `a[mid] == target` 时，不能立即返回，因为 `mid` 可能不是第一次出现的位置。需要继续向左搜索。

```
查找目标值 x 第一次出现的位置：

left = 0, right = n-1
while left <= right:
    mid = (left + right) / 2
    if a[mid] >= x:      // 目标在左半部分（包括mid）
        right = mid - 1
    else:                 // 目标在右半部分
        left = mid + 1

最后检查 a[left] 是否等于 x
```

**图解过程**（查找 `3` 在序列 `[1, 3, 3, 3, 5]` 中的位置）：

```
初始: [1, 3, 3, 3, 5]  left=0, right=4
        L        M     R

第1轮: mid=2, a[2]=3 >= 3, right=1
       [1, 3, 3, 3, 5]
        L  R
        M

第2轮: mid=0, a[0]=1 < 3, left=1
       [1, 3, 3, 3, 5]
           L
           R
           M

第3轮: mid=1, a[1]=3 >= 3, right=0
       left=1, right=0, 循环结束

检查: a[1]=3 == 3，返回位置 2（编号从1开始）
```

### 方法二：使用 STL lower_bound

`lower_bound(begin, end, x)` 返回**第一个 ≥ x 的元素的迭代器**。

```cpp
auto it = lower_bound(a.begin(), a.end(), x);
if (it != a.end() && *it == x) {
    // 找到了，位置是 it - a.begin() + 1
} else {
    // 没找到
}
```

**本质**：`lower_bound` 内部就是二分查找，找第一次出现的位置。

## 时间复杂度分析

| 操作 | 复杂度 |
|------|--------|
| 读入数据 | $O(n)$ |
| 每次查询 | $O(\log n)$ |
| 总复杂度 | $O(n + m\log n)$ |

对于 $n=10^6, m=10^5$：
- 暴力：$O(nm) = 10^{11}$，超时
- 二分：$O(m\log n) = 10^5 \times 20 = 2 \times 10^6$，轻松通过

## 代码实现

### 方法一：手写二分

```cpp
#include <cstdio>
using namespace std;

int a[1000010];

int main() {
    int n, m;
    scanf("%d%d", &n, &m);

    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    while (m--) {
        int x;
        scanf("%d", &x);

        int left = 0, right = n - 1;
        int ans = -1;

        while (left <= right) {
            int mid = left + (right - left) / 2;  // 防溢出写法

            if (a[mid] >= x) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }

        // 循环结束后，left 是第一个 >= x 的位置
        if (left < n && a[left] == x) {
            ans = left + 1;  // 编号从1开始
        }

        printf("%d ", ans);
    }
    printf("\n");
    return 0;
}
```

### 方法二：STL lower_bound

```cpp
#include <cstdio>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n, m;
    scanf("%d%d", &n, &m);

    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    while (m--) {
        int x;
        scanf("%d", &x);

        auto it = lower_bound(a.begin(), a.end(), x);
        if (it != a.end() && *it == x) {
            printf("%d ", (int)(it - a.begin()) + 1);
        } else {
            printf("-1 ");
        }
    }
    printf("\n");
    return 0;
}
```

## 关键技巧总结

### 1. 二分查找模板

```cpp
// 找第一个 >= x 的位置（lower_bound）
int left = 0, right = n - 1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (a[mid] >= x) {
        right = mid - 1;
    } else {
        left = mid + 1;
    }
}
// left 就是答案位置（需要验证 a[left] == x）
```

### 2. 防溢出写法

```cpp
// 错误写法：可能溢出
int mid = (left + right) / 2;

// 正确写法
int mid = left + (right - left) / 2;
```

### 3. 快速IO

数据量大时，使用 `scanf/printf` 比 `cin/cout` 快。

## 易错点

1. **编号从1开始**：数组下标从0开始，输出时要 +1
2. **找第一次出现**：不能在 `a[mid] == x` 时直接返回，要继续向左搜索
3. **边界检查**：循环结束后要验证 `left` 是否越界、`a[left]` 是否等于目标值
4. **输入输出效率**：大数据量时用 `scanf/printf`
