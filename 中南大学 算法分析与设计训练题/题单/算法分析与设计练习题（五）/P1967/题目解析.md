# P1967 [NOIP 2013 提高组] 货车运输

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P1967

知识点：图论、最大生成树、LCA、树上路径最小值

## 题目简述

> A 国有 n 座城市、m 条双向道路，每条道路有载重限制 z。现有 q 辆货车，每辆从城市 x 前往城市 y，求在不超过限重的情况下最多能运多重的货物。若无法到达，输出 -1。
>
> 数据范围：n < 10⁴，m < 5×10⁴，q < 3×10⁴。
>
> 时间限制：1S，空间限制：128MB。

## 题目分析

### 详细版

**1. 读题**

货车从 x 到 y，路径上每条路都有各自的限重。为了不超载，货车载重不能超过路径上最小限重。题目要求的是所有路径中，这个最小限重的最大值，也就是“最大瓶颈路径”问题。

**2. 性质观察**

最大瓶颈路径有一个经典结论：将图的所有边按权值从大到小排序，依次加入并查集，第一次使 x 和 y 连通时，当前边的权值就是 x 到 y 的最大瓶颈值。

这等价于：构造一张**最大生成树**，则 x 到 y 在树上的唯一路径上的最小边权，就是答案。

**3. 数据结构与算法选择**

- 使用 **Kruskal** 算法构建最大生成树。
- 在树上使用 **倍增 LCA** 维护从节点到其 2^k 级祖先路径上的最小边权。
- 每次查询时，先让两个节点跳到同一深度，再一起向上跳，过程中维护最小边权。

**4. 程序设计**

- 读入边，按权值降序排序。
- Kruskal 建最大生成树，同时用并查集维护连通性。
- 对每个连通块的根节点，DFS 预处理每个节点的深度、parent[0]、minw[0]。
- 倍增预处理 parent[k][i] 和 minw[k][i]。
- 处理每个询问：若两点不在同一连通块输出 -1；否则通过 LCA 查询路径最小边权。

**5. 时空复杂度分析**

时间复杂度：Kruskal 排序 O(m log m)，倍增预处理 O(n log n)，每次查询 O(log n)，总复杂度 O((m+n+q) log n)。
空间复杂度：O(n log n + m)。

### 省流版

最大生成树 + 倍增 LCA 维护路径最小边权，树上两点路径最小值即为最大载重。

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

struct Edge{
	int u, v, w;
}edge[50010];

struct Node{
	int to;
	int w;
};

bool cmp(Edge a, Edge b){
	return a.w > b.w;
}

int n, m, q;
int fa[10010];
int depth[10010];
int parent[20][10010];
int minw[20][10010];
vector<Node> tree[10010];

int find(int x){
	if(fa[x] == x) return x;
	return fa[x] = find(fa[x]);
}

void dfs(int u, int p){
	parent[0][u] = p;
	for(int i = 0; i < (int)tree[u].size(); i++){
		int v = tree[u][i].to;
		int w = tree[u][i].w;
		if(v == p) continue;
		depth[v] = depth[u] + 1;
		minw[0][v] = w;
		dfs(v, u);
	}
}

int lca(int u, int v){
	int ans = 1000000000;
	if(depth[u] < depth[v]){
		int t = u; u = v; v = t;
	}
	for(int k = 15; k >= 0; k--){
		if(depth[parent[k][u]] >= depth[v]){
			if(minw[k][u] < ans) ans = minw[k][u];
			u = parent[k][u];
		}
	}
	if(u == v) return ans;
	for(int k = 15; k >= 0; k--){
		if(parent[k][u] != parent[k][v]){
			if(minw[k][u] < ans) ans = minw[k][u];
			if(minw[k][v] < ans) ans = minw[k][v];
			u = parent[k][u];
			v = parent[k][v];
		}
	}
	if(minw[0][u] < ans) ans = minw[0][u];
	if(minw[0][v] < ans) ans = minw[0][v];
	return ans;
}

int main(){
	scanf("%d%d", &n, &m);
	for(int i = 0; i < m; i++){
		scanf("%d%d%d", &edge[i].u, &edge[i].v, &edge[i].w);
	}

	sort(edge, edge + m, cmp);
	for(int i = 1; i <= n; i++) fa[i] = i;
	for(int i = 0; i < m; i++){
		int fu = find(edge[i].u);
		int fv = find(edge[i].v);
		if(fu != fv){
			fa[fu] = fv;
			tree[edge[i].u].push_back((Node){edge[i].v, edge[i].w});
			tree[edge[i].v].push_back((Node){edge[i].u, edge[i].w});
		}
	}

	memset(minw, 0x3f, sizeof(minw));
	for(int i = 1; i <= n; i++){
		if(fa[i] == i){
			depth[i] = 1;
			minw[0][i] = 1000000000;
			dfs(i, i);
		}
	}

	for(int k = 1; k <= 15; k++){
		for(int i = 1; i <= n; i++){
			parent[k][i] = parent[k-1][parent[k-1][i]];
			minw[k][i] = min(minw[k-1][i], minw[k-1][parent[k-1][i]]);
		}
	}

	scanf("%d", &q);
	for(int i = 0; i < q; i++){
		int u, v;
		scanf("%d%d", &u, &v);
		if(find(u) != find(v)){
			printf("-1\n");
		}else{
			printf("%d\n", lca(u, v));
		}
	}
}
```
