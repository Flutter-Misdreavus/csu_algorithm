# P2984 [USACO10FEB] Chocolate Giving S

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P2984

知识点：图论、最短路、Dijkstra

## 题目简述

> FJ 居住在农场 1。有 N 个农场、M 条双向道路。B 头奶牛，第 i 头想从农场 P_i 出发，先到农场 1 取礼物，再送到农场 Q_i。求每头奶牛至少要走多远。
>
> 数据范围：N ≤ 50000，M ≤ 100000，B ≤ 25000。
>
> 时间限制：1S，空间限制：125MB。

## 题目分析

### 详细版

**1. 读题**

每头奶牛的路线固定为 P_i → 1 → Q_i。由于道路是双向的，从 P_i 到 1 的距离等于从 1 到 P_i 的距离。因此每头奶牛的总路程就是 `dis[P_i] + dis[Q_i]`。

**2. 性质观察**

所有询问的出发点和终点都是相对于农场 1 而言的，因此只需要以 1 为源点跑一次最短路，即可 O(1) 回答每个询问。

**3. 数据结构与算法选择**

图是双向带权图，边权为正。使用 **堆优化 Dijkstra**，时间复杂度 O((N+M) log N)。

**4. 程序设计**

- 建无向图邻接表。
- 从节点 1 开始跑 Dijkstra，得到 dis[i]。
- 对每个询问输出 `dis[P_i] + dis[Q_i]`。

**5. 时空复杂度分析**

时间复杂度：Dijkstra 为 O((N+M) log N)，询问 O(B)。
空间复杂度：O(N + M)。

### 省流版

一次 Dijkstra 预处理农场 1 到所有农场的最短路，每次询问直接求和。

## 代码实现

![AC截图](./P2984AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

const long long INF = 0x3f3f3f3f3f3f3f3fLL;

int n, m, B;
vector<pair<int, int>> g[50010];
long long dis[50010];
int vis[50010];

struct State{
	int u;
	long long d;
	bool operator<(const State& other) const {
		return d > other.d;
	}
};

void dijkstra(){
	priority_queue<State> pq;
	memset(dis, 0x3f, sizeof(dis));
	dis[1] = 0;
	pq.push((State){1, 0});
	while(!pq.empty()){
		State cur = pq.top();
		pq.pop();
		int u = cur.u;
		if(vis[u]) continue;
		vis[u] = 1;
		for(int i = 0; i < (int)g[u].size(); i++){
			int v = g[u][i].first;
			int w = g[u][i].second;
			if(dis[u] + w < dis[v]){
				dis[v] = dis[u] + w;
				pq.push((State){v, dis[v]});
			}
		}
	}
}

int main(){
	scanf("%d%d%d", &n, &m, &B);
	for(int i = 0; i < m; i++){
		int u, v, w;
		scanf("%d%d%d", &u, &v, &w);
		g[u].push_back(make_pair(v, w));
		g[v].push_back(make_pair(u, w));
	}

	dijkstra();

	for(int i = 0; i < B; i++){
		int p, q;
		scanf("%d%d", &p, &q);
		printf("%lld\n", dis[p] + dis[q]);
	}
}
```
