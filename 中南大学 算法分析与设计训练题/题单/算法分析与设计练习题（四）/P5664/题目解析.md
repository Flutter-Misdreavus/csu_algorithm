# P5664 [CSP-S 2019] Emiya 家今天的饭

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P5664

知识点：动态规划、组合计数、容斥思想、状态压缩优化

## 题目简述

> Emiya 掌握 $n$ 种烹饪方法、$m$ 种主要食材。用烹饪方法 $i$ 和食材 $j$ 可以做出 $a_{i,j}$ 道不同的菜。
>
> 现在 Emiya 要选出一桌饭招待朋友，要求：
> - 至少做一道菜；
> - 每道菜的烹饪方法互不相同；
> - 每种主要食材至多在一半的菜中被使用（即对 $k$ 道菜，每种食材出现次数 $\le \lfloor k/2 \rfloor$）。
>
> 求合法方案数，对 $998,244,353$ 取模。
>
> 数据范围：$1 \le n \le 100$，$1 \le m \le 2000$，$0 \le a_{i,j} \lt 998,244,353$。

## 题目分析

### 详细版

**1. 读题**

本题是一个组合计数问题。由于每道菜的烹饪方法互不相同，而烹饪方法只有 $n$ 种，因此最多选 $n$ 道菜，且每种烹饪方法至多使用一次。

对于第 $i$ 种烹饪方法，可以选择不做菜，或者从 $m$ 种食材中选择一种做一道菜。若选择食材 $j$，则有 $a_{i,j}$ 种不同的菜可选。

**2. 总方案数（不考虑食材限制）**

设第 $i$ 种烹饪方法对应的总菜数为 $s_i = \sum_{j=1}^{m} a_{i,j}$。

对于第 $i$ 种烹饪方法，有 $1 + s_i$ 种选择：不做菜，或从 $s_i$ 道菜中选一道。

因此，包含任意道菜的方案总数为：
$$All = \prod_{i=1}^{n} (1 + s_i) - 1$$
减去 1 是为了排除“一道菜都不做”的情况。

**3. 不合法方案的判定**

不合法方案是指：存在某种食材 $j$，其在最终选出的菜中出现的次数超过总菜数的一半。

关键观察：**不可能同时有两种食材都超过一半**。假设食材 $j_1$ 出现 $k_1$ 次，食材 $j_2$ 出现 $k_2$ 次，若两者都超过一半，则 $k_1 + k_2 > k$（$k$ 为总菜数），矛盾。

因此，不合法方案数可以按“是哪一种食材超过一半”分类，直接相加：
$$Illegal = \sum_{j=1}^{m} Illegal_j$$
其中 $Illegal_j$ 表示食材 $j$ 出现次数超过一半的方案数。

**4. 计算 $Illegal_j$：动态规划**

对于固定的食材 $j$，我们关心的是：食材 $j$ 被使用的次数是否超过其他食材被使用的次数。

设 $dp[k]$ 表示处理完前若干种烹饪方法后，**食材 $j$ 使用次数与其他食材使用次数之差为 $k$** 的方案数。由于 $k$ 可能为负，实际实现时用一个偏移量 $offset = n$ 来处理。

初始状态：$dp[offset + 0] = 1$，表示一种烹饪方法都没处理时，差值为 0。

状态转移（处理第 $i$ 种烹饪方法）：
- 第 $i$ 种烹饪方法不做菜：差值不变，方案数 $\times 1$。
- 第 $i$ 种烹饪方法做食材 $j$ 的菜：差值 $+1$，方案数 $\times a_{i,j}$。
- 第 $i$ 种烹饪方法做其他食材的菜：差值 $-1$，方案数 $\times (s_i - a_{i,j})$。

即：
$$new\_dp[offset + k] = dp[offset + k] \times 1 + dp[offset + k - 1] \times a_{i,j} + dp[offset + k + 1] \times (s_i - a_{i,j})$$

处理完所有 $n$ 种烹饪方法后，食材 $j$ 出现次数超过一半的方案数为：
$$Illegal_j = \sum_{k=1}^{n} dp[offset + k]$$

**5. 最终答案**

$$Ans = (All - Illegal + mod) \% mod$$

**6. 时空复杂度分析**

时间复杂度：$O(m \cdot n^2)$。对于每种食材 $j$（共 $m$ 种），需要做一次 $O(n^2)$ 的动态规划。$n \le 100$，$m \le 2000$，总计算量约为 $2 \times 10^7$，可以通过。

空间复杂度：$O(n^2)$ 或 $O(n)$。只需维护一维 DP 数组即可。

### 省流版

总方案数减去不合法方案数。总方案数为 $\prod_{i=1}^{n}(1 + s_i) - 1$。不合法方案按“哪种食材超过一半”分类，由于不可能有两种食材同时超过一半，可直接相加。对每种食材 $j$ 做 DP，设状态为“食材 $j$ 使用次数 - 其他食材使用次数”，转移时分别考虑不选、选食材 $j$、选其他食材三种情况，最后累加差值大于 0 的状态。

## 代码实现

```cpp
#include <stdio.h>
#include <string.h>

using namespace std;

const int mod = 998244353;
const int maxn = 110;
const int maxm = 2010;
const int offset = 105;

long long menu[maxn][maxm];
long long sum[maxn];
long long dp[2 * maxn];

int main(){
    int n, m;
    scanf("%d%d", &n, &m);

    for(int i = 1; i <= n; i++){
        sum[i] = 0;
        for(int j = 1; j <= m; j++){
            scanf("%lld", &menu[i][j]);
            sum[i] = (sum[i] + menu[i][j]) % mod;
        }
    }

    // 总方案数：每行可选或不选，减去全不选
    long long all = 1;
    for(int i = 1; i <= n; i++){
        all = all * (1 + sum[i]) % mod;
    }
    all = (all - 1 + mod) % mod;

    // 不合法方案数：枚举哪种食材超过一半
    long long illegal = 0;
    for(int j = 1; j <= m; j++){
        memset(dp, 0, sizeof(dp));
        dp[offset] = 1; // 差值为 0

        for(int i = 1; i <= n; i++){
            // 倒序或正序均可，因为 new_dp 依赖的是上一轮 dp
            // 这里使用临时数组避免覆盖
            long long newDp[2 * maxn];
            memcpy(newDp, dp, sizeof(dp));

            for(int k = -n; k <= n; k++){
                int idx = offset + k;
                long long val = dp[idx];
                if(val == 0) continue;

                // 选食材 j，差值 +1
                if(k + 1 <= n){
                    newDp[offset + k + 1] = (newDp[offset + k + 1] + val * menu[i][j]) % mod;
                }
                // 选其他食材，差值 -1
                if(k - 1 >= -n){
                    long long other = (sum[i] - menu[i][j] + mod) % mod;
                    newDp[offset + k - 1] = (newDp[offset + k - 1] + val * other) % mod;
                }
                // 不选：差值不变，已经在初始化时乘了 1
            }

            memcpy(dp, newDp, sizeof(dp));
        }

        for(int k = 1; k <= n; k++){
            illegal = (illegal + dp[offset + k]) % mod;
        }
    }

    long long ans = (all - illegal + mod) % mod;
    printf("%lld\n", ans);

    return 0;
}
```
