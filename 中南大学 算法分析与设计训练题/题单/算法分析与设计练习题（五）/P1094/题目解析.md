# P1094 [NOIP 2007 普及组] 纪念品分组

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P1094

知识点：贪心、排序、双指针

## 题目简述

> 把 $n$ 件价格分别为 $P_i$ 的纪念品分组，每组最多 $2$ 件，且每组价格之和不超过上限 $w$，求最少的分组数。
>
> 数据范围：$1\le n\le 3\times 10^4$，$80\le w\le 200$，$5\le P_i\le w$。
>
> 时间限制：1S，空间限制：128MB。

## 题目分析

### 详细版

**1. 读题**

每组至多 2 件、组内和 $\le w$，要让组数最少——等价于让「两件配成一组」的情况尽可能多。

**2. 性质观察**

**贪心策略**：先将价格升序排序，再用双指针从两端向中间靠拢。每次考虑当前最贵的物品（右指针 `right`）：

- 若它能和当前最便宜的物品（左指针 `left`）凑成一组（和 $\le w$），就把两件配成一组，`left++`、`right--`；
- 否则最贵的物品只能单独成组，`right--`。

无论哪种情况组数 `zu++`。这样保证最贵的物品总能搭上一个尽量便宜的物品，是分组数最少的最优解。

**边界**：当 `left == right` 时还剩最后一件物品落单，需单独成一组（`zu++`）。

**3. 数据结构与算法选择**

- 数组 `gift[]` 存价格，`sort` 升序排序；
- 双指针 `left`、`right` 从两端扫描；
- 计数器 `zu`。

**4. 程序设计**

1. 读入上限 $w$、件数 $n$ 与各价格，升序排序；
2. `left=0, right=n-1`，当 `left < right`：
   - 若 `gift[left]+gift[right] > w`：仅最贵的单独成组，`right--`，`zu++`；
   - 否则两件成组，`left++`、`right--`，`zu++`；
3. 若 `left == right` 还剩一件，`zu++`；
4. 输出 `zu`。

**5. 时空复杂度分析**

排序 $O(n\log n)$，双指针扫描 $O(n)$，总时间 $O(n\log n)$，空间 $O(n)$。$n\le 3\times 10^4$ 可以通过。

### 省流版

贪心 + 双指针。价格升序排序后，最贵的物品尝试与最便宜的物品配对：能配（和 $\le w$）则两件一组、双指针内移；不能配则最贵的单独成组、右指针内移。每步组数 +1，注意中间剩一件要单独成组。时间复杂度 $O(n\log n)$。

## 代码实现

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <queue>
#include <stack>
#include <string>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int gift[30004];

int main(){
	int n, w;
	int left, right;
	int zu = 0;

	scanf("%d", &w);
	scanf("%d", &n);
	for(int i = 0; i < n; i++){
		scanf("%d", &gift[i]);
	}

	left = 0;
	right = n - 1;
	sort(gift, gift + n);

	while(left < right){
		if(gift[left] + gift[right] > w){
			right--;
			zu++;
		}else{
			left++;
			right--;
			zu++;
		}
	}

	if(left == right){
		zu++;
		// 最后一组
	}

	printf("%d\n", zu);
}
```
