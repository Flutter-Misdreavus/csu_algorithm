# P1359 租用游艇

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P1359

知识点：动态规划、最短路

## 题目简述

> 长江上有 n 个游艇出租站 1, 2, …, n。游客可在出租站租用游艇，并在下游任意出租站归还。已知从出租站 i 到出租站 j（i < j）的租金 r(i,j)。求从出租站 1 到出租站 n 所需的最少租金。
>
> 数据范围：1 ≤ n ≤ 200，保证计算过程中任何时刻数值不超过 10⁶。
>
> 时间限制：1S，空间限制：125MB。

## 题目分析

### 详细版

**1. 读题**

游艇只能向下游行驶，即只能从编号小的站驶向编号大的站。因此整个路径具有严格的拓扑顺序，不存在环。

**2. 性质观察**

由于站点只能按编号递增方向前进，从 1 到 n 的最低租金问题满足最优子结构：如果从 1 到 j 的最优路径中，最后一步是从某个 i（i < j）直接到达 j 的，那么从 1 到 i 也必须是最优的。因此可以按站点编号从小到大递推。

**3. 数据结构与算法选择**

使用一维数组 `dp[j]` 表示从出租站 1 到出租站 j 的最少租金。状态转移方程：

```
dp[j] = min(dp[i] + r[i][j])  （其中 1 ≤ i < j）
```

初始状态 `dp[1] = 0`，最终答案为 `dp[n]`。

**4. 程序设计**

- 读入站点数 n。
- 读入上三角租金矩阵 `r[i][j]`（i < j）。
- 初始化 `dp[1] = 0`。
- 对于每个 j 从 2 到 n，枚举所有前驱站 i，取最小值。
- 输出 `dp[n]`。

**5. 时空复杂度分析**

时间复杂度：枚举每个 j 及其所有前驱 i，共 O(n²)。
空间复杂度：需要存储租金矩阵和 dp 数组，O(n²)。

### 省流版

按站点顺序 DP，`dp[j]` 表示从 1 到 j 的最小租金，枚举前一个中转站 i 转移即可。

## 代码实现

![AC截图](./P1359AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int n;
int r[210][210];
int dp[210];

int main(){
	scanf("%d", &n);
	for(int i = 1; i <= n - 1; i++){
		for(int j = i + 1; j <= n; j++){
			scanf("%d", &r[i][j]);
		}
	}

	dp[1] = 0;
	for(int j = 2; j <= n; j++){
		dp[j] = r[1][j];
		for(int i = 2; i < j; i++){
			if(dp[i] + r[i][j] < dp[j]){
				dp[j] = dp[i] + r[i][j];
			}
		}
	}

	printf("%d\n", dp[n]);
}
```
