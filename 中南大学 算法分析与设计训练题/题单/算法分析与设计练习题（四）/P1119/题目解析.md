# P1119 灾后重建

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P1119

知识点：图论、最短路、Floyd、离线处理

## 题目简述

> B 地区有 N 个村庄（编号 0 到 N-1）和 M 条无向公路。每个村庄有一个重建完成时间 t[i]，只有重建完成的村庄才能通行。给出 Q 个询问 (x, y, t)，询问在第 t 天从村庄 x 到村庄 y 的最短路径长度。若 x 或 y 尚未重建完成，或两村在第 t 天不连通，则输出 -1。
>
> 数据保证 t[i] 非降序排列，询问的 t 也是非降序的。
>
> 时间限制：1S，空间限制：125MB。

## 题目分析

### 详细版

**1. 读题**

本题在普通最短路问题的基础上增加了时间维度：村庄不是一开始就全部可用，而是随着时间推移逐个开放。询问也是按时间顺序给出的。

**2. 性质观察**

由于村庄重建时间 `t[i]` 和询问时间 `t` 都是非降序的，因此可以使用“离线”思想：随着时间推进，不断将新开放的村庄加入图中，并更新全源最短路。

Floyd 算法的本质是逐个把点作为中间点进行松弛。这里完全可以复用这一思想：每当一个村庄 k 在时间 t 之前或当天重建完成，就用它作为中间点，执行一次 Floyd 的松弛操作。

**3. 数据结构与算法选择**

使用二维数组 `dis[i][j]` 记录村庄 i 到 j 的当前最短路。算法选择 **Floyd 增量算法**，配合离线处理所有询问。

**4. 程序设计**

- 初始化 `dis` 为 INF，`dis[i][i] = 0`。
- 读入 M 条边，更新直接相连的村庄距离。
- 设置指针 `k = 0`，表示当前已加入的中间点数量。
- 对每个询问 (x, y, t)：
  - 将所有 `t[i] ≤ t` 且尚未加入的村庄 i 依次作为中间点，执行 Floyd 松弛。
  - 如果 `t[x] > t` 或 `t[y] > t`，说明起点或终点尚未开放，输出 -1。
  - 否则若 `dis[x][y]` 仍为 INF，说明不连通，输出 -1。
  - 否则输出 `dis[x][y]`。

**5. 时空复杂度分析**

时间复杂度：最坏情况下所有 N 个村庄都会被加入，每次加入执行 O(N²) 松弛，加上 Q 次查询，总复杂度为 O(N³ + Q)。
空间复杂度：距离矩阵 O(N²)。

### 省流版

离线按时间顺序处理询问，用 Floyd 逐个加入已重建村庄作为中间点，实时回答最短路。

## 代码实现

![AC截图](./P1119AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int n, m, Q;
int tim[210];
int dis[210][210];
const int INF = 0x3f3f3f3f;

int main(){
	scanf("%d%d", &n, &m);
	for(int i = 0; i < n; i++){
		scanf("%d", &tim[i]);
	}
	memset(dis, 0x3f, sizeof(dis));
	for(int i = 0; i < n; i++){
		dis[i][i] = 0;
	}
	for(int i = 0; i < m; i++){
		int u, v, w;
		scanf("%d%d%d", &u, &v, &w);
		dis[u][v] = w;
		dis[v][u] = w;
	}

	int k = 0;
	scanf("%d", &Q);
	for(int q = 0; q < Q; q++){
		int x, y, t;
		scanf("%d%d%d", &x, &y, &t);
		while(k < n && tim[k] <= t){
			for(int i = 0; i < n; i++){
				for(int j = 0; j < n; j++){
					if(dis[i][k] + dis[k][j] < dis[i][j]){
						dis[i][j] = dis[i][k] + dis[k][j];
					}
				}
			}
			k++;
		}
		if(tim[x] > t || tim[y] > t){
			printf("-1\n");
		}else if(dis[x][y] == INF){
			printf("-1\n");
		}else{
			printf("%d\n", dis[x][y]);
		}
	}
}
```
