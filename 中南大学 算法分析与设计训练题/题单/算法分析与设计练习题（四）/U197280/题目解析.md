# U197280 【模板】最长公共子序列

## 题目信息

题目链接：https://www.luogu.com.cn/problem/U197280

知识点：动态规划、最长公共子序列（LCS）

## 题目简述

> 给定两个由大写字母组成的字符串 $X$、$Y$，求它们最长公共子序列的长度。子序列允许不连续，但相对顺序保持不变。
>
> 数据范围：字符串长度不超过 $200$（题面另有「长度 $\le 1000$」的描述，实现按更小的约束即可）。
>
> 时间限制：1S，空间限制：128MB。

## 题目分析

### 详细版

**1. 读题**

最长公共子序列（LCS）模板题。LCS 与最长公共子串不同，子序列不要求连续。

**2. 性质观察**

设 `dp[i][j]` 表示 $X$ 的前 $i$ 个字符与 $Y$ 的前 $j$ 个字符的 LCS 长度。考虑末尾字符：

- 若 $X_i=Y_j$，则这对字符可同时计入 LCS：$dp[i][j]=dp[i-1][j-1]+1$；
- 否则，至少要放弃其中一个的末字符：$dp[i][j]=\max(dp[i-1][j],\,dp[i][j-1])$。

边界 `dp[0][*]=dp[*][0]=0`。

**3. 数据结构与算法选择**

- 用 `string` 读入两串，二维数组 `dp[205][205]`；
- 下标从 $1$ 开始填表，方便处理边界。

**4. 程序设计**

1. 读入两个字符串 $X,Y$，记长度 `xl,yl`；
2. 双重循环 $i=1..xl$、$j=1..yl$，按上面的转移方程填表（比较 `x[i-1]` 与 `y[j-1]`）；
3. 输出 `dp[xl][yl]`。

**5. 时空复杂度分析**

填表 $O(|X|\cdot|Y|)$，空间 $O(|X|\cdot|Y|)$。本题串长很小，可以轻松通过。

### 省流版

LCS 模板。`dp[i][j]`：$X$ 前 $i$、$Y$ 前 $j$ 的最长公共子序列长度。末字符相等取 `dp[i-1][j-1]+1`，否则取 `max(dp[i-1][j], dp[i][j-1])`。时间复杂度 $O(|X||Y|)$。

## 代码实现

![AC截图](./U197280AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <queue>
#include <vector>
#include <list>
#include <string>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

char buff[205];
string x, y;
int dp[205][205];

int main(){
	int xl, yl;
	memset(dp, 0, sizeof(dp));

	scanf("%s", buff);
	x = buff;
	scanf("%s", buff);
	y = buff;
	xl = x.size();
	yl = y.size();

	for(int i = 1; i <= xl; i++){
		for(int j = 1; j <= yl; j++){
			if(x[i - 1] == y[j - 1]){
				dp[i][j] = dp[i - 1][j - 1] + 1;
			}else{
				dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
			}
		}
	}

	printf("%d\n", dp[xl][yl]);
}
```
