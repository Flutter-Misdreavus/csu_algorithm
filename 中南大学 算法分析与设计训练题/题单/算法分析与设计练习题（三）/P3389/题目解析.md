# P3389 【模板】高斯消元法

## 题目信息

- **题目链接**：https://www.luogu.com.cn/problem/P3389
- **知识点**：高斯消元、线性方程组
- **时间限制**：1.00s
- **内存限制**：500MB

## 题目简述

> 给定一个 $n \times n$ 的线性方程组，求解 $x_1, x_2, \dots, x_n$。若不存在唯一解或无解，输出 `No Solution`。
>
> 数据范围：$1 \le n \le 100$，$|a_i| \le 10^4$，$|b| \le 10^4$。

## 题目分析

### 详细版

**1. 读题**

题目要求解线性方程组，属于高斯消元模板。需要注意存在唯一解时才输出解，否则输出 `No Solution`。

**2. 高斯消元（列主元）**

- 将方程组写成增广矩阵，最后一列为常数 $b$。
- 对每一列选主元：在当前行下方找绝对值最大的元素所在行，与当前行交换。
- 若主元绝对值小于 `EPS`，说明系数矩阵奇异，不存在唯一解，输出 `No Solution`。
- 将主元行归一化，使主元变为 $1$。
- 用主元行消去其他所有行对应列的元素，最终得到简化行阶梯形，此时最后一列即为解。

**3. 输出**

- 有唯一解时，按顺序输出每个 $x_i$，保留两位小数。
- 题目 special judge 允许输出 `-0.00`，因此不需要额外处理负零。

**4. 时空复杂度分析**

- 时间复杂度：$O(n^3)$，$n \le 100$ 完全可接受。
- 空间复杂度：$O(n^2)$。

### 省流版

列主元高斯消元把增广矩阵化为简化行阶梯形；若主元为 $0$ 则输出 `No Solution`，否则直接输出最后一列。

```cpp
// P3389 【模板】高斯消元法
/*
链接：https://www.luogu.com.cn/problem/P3389
知识点：高斯消元
*/
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

const double EPS = 1e-7;

double a[105][106];

int main(){
    int n;
    scanf("%d", &n);
    for(int i = 0; i < n; i++){
        for(int j = 0; j <= n; j++){
            scanf("%lf", &a[i][j]);
        }
    }

    for(int i = 0; i < n; i++){
        int pivot = i;
        for(int r = i + 1; r < n; r++){
            if(fabs(a[r][i]) > fabs(a[pivot][i])){
                pivot = r;
            }
        }
        if(fabs(a[pivot][i]) < EPS){
            printf("No Solution\n");
            return 0;
        }
        if(pivot != i){
            for(int j = i; j <= n; j++){
                swap(a[i][j], a[pivot][j]);
            }
        }

        double div = a[i][i];
        for(int j = i; j <= n; j++){
            a[i][j] /= div;
        }

        for(int r = 0; r < n; r++){
            if(r == i) continue;
            double factor = a[r][i];
            if(fabs(factor) < EPS) continue;
            for(int j = i; j <= n; j++){
                a[r][j] -= factor * a[i][j];
            }
        }
    }

    for(int i = 0; i < n; i++){
        printf("%.2f\n", a[i][n]);
    }
    return 0;
}
```
