# 题目名称

[JSOI2007] 建筑抢修

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P4053

知识点：贪心、优先队列（带反悔贪心）

## 题目简述

> 有 n 个建筑需要修理，每个建筑 i 有两个属性：修理时间 T1 和报废时间 T2。如果在 T2 时刻之前没有完成修理，建筑就会报废（刚好在 T2 时刻完成不会报废）。求最多能修理好的建筑数量。
>
> 数据范围：1 ≤ n ≤ 150000，1 ≤ T1 < T2 < 2^31
>
> 时间限制：1S，空间限制：128MB

## 题目分析

### 详细版

1. **读题**：n 个建筑，每个有修理时间 T1 和报废时间 T2。同一时刻只能修理一个建筑，求能修理的最大数量。

2. **性质观察**：
   - 报废时间越早的建筑越紧迫，应该优先处理 —— 按 T2 升序排序
   - 当处理到某个建筑发现时间不够时，可以考虑用较短的修理时间替换已选中的较长修理时间
   - 用最大堆维护已选中建筑的修理时间，可以快速找到并替换最长的一项

3. **程序设计**：
   - 按报废时间 T2 升序排序所有建筑
   - 维护当前已用时间 `time` 和最大堆 `built`（存储已选建筑的 T1）
   - 遍历每个建筑：
     - 将当前建筑的 T1 加入堆，`time += T1`
     - 若 `time > T2`，说明无法按时完成，将堆顶（最大 T1）弹出，`time -= 弹出值`
     - 若弹出的 T1 大于当前建筑的 T1，则把当前建筑加入堆；否则把被弹出的建筑重新加入堆
   - 最终堆的大小即为答案

4. **数据结构与算法选择**：
   - `priority_queue` 实现最大堆，维护已选建筑的修理时间
   - 时间复杂度 O(n log n)，空间复杂度 O(n)

5. **时空复杂度分析**：
   - 时间：排序 O(n log n) + 遍历 O(n log n) = O(n log n)
   - 空间：堆中最多存储 n 个元素，O(n)

### 省流版

按报废时间排序，依次处理每个建筑，用最大堆维护已选建筑的修理时间。当时间超出当前建筑的报废时间时，弹出堆中最大的修理时间进行替换（相当于反悔），最终堆的大小即为最多能修理的建筑数。

## 代码实现

![AC截图](./P4053AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <queue>
#include <vector>
#include <algorithm>

using namespace std;

auto cmp = [](auto &a, auto &b) {
    if (a.second == b.second) {
        return a.first > b.first;
    } else {
        return a.second > b.second;
    }
};
priority_queue<pair<long long int, long long int>, vector<pair<long long int, long long int>>, decltype(cmp)> building(cmp);

auto cmp2 = [](auto &a, auto &b) {
    return a.first < b.first;
};
priority_queue<pair<long long int, long long int>, vector<pair<long long int, long long int>>, decltype(cmp2)> built(cmp2);

int main() {
    long long int n;
    long long int s = 0;
    long long int t1, t2;
    long long int time = 0;

    scanf("%lld", &n);
    for (long long int i = 0; i < n; i++) {
        scanf("%lld%lld", &t1, &t2);
        building.push({t1, t2});
    }

    while (!building.empty()) {
        t1 = building.top().first;
        t2 = building.top().second;
        building.pop();

        if (time + t1 <= t2) {
            s++;
            time += t1;
            built.push({t1, t2});
        } else {
            if (t1 < built.top().first) {
                time -= built.top().first;
                time += t1;
                building.push(built.top());
                built.pop();
                built.push({t1, t2});
            }
        }
    }

    printf("%lld\n", s);
}
```
