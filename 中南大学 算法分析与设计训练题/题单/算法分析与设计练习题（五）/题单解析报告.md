### 2.1 B2168 【模板】哈夫曼编码

**题目链接**：https://www.luogu.com.cn/problem/B2168

**知识点**：贪心、哈夫曼树、优先队列（小根堆）

**题目简述**：

> 给定 $n$ 个互不相同的单词及其频次 $w_i$，构造一种哈夫曼编码方案，使带权路径长度（$\sum$ 编码长度 $\times$ 频次）最小，输出任意一种合法方案，单词顺序与输入一致。
>
> 数据范围：$1\le n\le 1000$，$1\le w_i\le 10^9$。

#### 详细分析

**1. 读题**

哈夫曼编码模板。核心是构造哈夫曼树：频次越高的单词编码越短，从而使 WPL 最小。题目接受任意一种最优方案。

**2. 性质观察**

哈夫曼树的贪心构造：每次取出当前权值**最小的两个**节点合并成一个新节点（权值为两者之和），重复直到只剩一个根。合并时左分支记 $0$、右分支记 $1$，从根到叶子的路径即为该单词的编码。频次大的叶子离根近、编码短，保证 WPL 最小（贪心可证最优）。

**边界**：$n=1$ 时无法构成二叉树分支，需特判，直接给该单词编码 `0`。

**3. 数据结构与算法选择**

- 节点结构体 `NODE{w, id, l, r}`，叶子记录单词编号 `id`，内部节点 `id=-1`；
- **小根堆** `priority_queue`（比较器 `w` 升序）维护当前节点集合，每次弹出两个最小的合并；
- 建树完成后从根 DFS，沿左 $0$ 右 $1$ 累积路径字符串，到叶子时写入 `ans[id]`；
- 最后按输入顺序输出。

**4. 程序设计**

1. 特判 $n=1$：直接输出该单词与编码 `0`；
2. 读入 $n$ 个单词与频次，各建一个叶子节点入堆；
3. 当堆中节点数 $>1$：弹出两个最小节点 $a,b$，合并成 `newNode(a->w+b->w, -1, a, b)` 入堆；
4. 取根，`dfs(root, path, 0)`：到叶子写 `strcpy(ans[id], path)`，否则向左追加 `'0'`、向右追加 `'1'`；
5. 按输入顺序逐行输出单词及其编码。

**5. 时空复杂度分析**

建树需 $n-1$ 次合并，每次堆操作 $O(\log n)$，建树 $O(n\log n)$；DFS 遍历 $O(n\times\text{编码长度})$。$n\le 1000$ 可以通过。频次累加和达 $10^{12}$ 量级，权值用 `long long`。

#### 省流版

哈夫曼树贪心：小根堆每次取两个最小权值节点合并，直到剩一个根；左 $0$ 右 $1$，DFS 到叶子得到各单词编码。注意 $n=1$ 特判（编码记为 `0`），权值用 `long long`。建树 $O(n\log n)$。

#### 代码实现

![AC截图](./B2168/B2168AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <queue>
#include <vector>
#include <list>
#include <set>
#include <map>
#include <string>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

struct NODE {
    long long w;
    int id;          // 叶子编号，非叶子 = -1
    NODE *l, *r;
};

struct CMP {
    bool operator()(NODE* a, NODE* b) const {
        return a->w > b->w; // 小根堆
    }
};

priority_queue<NODE*, vector<NODE*>, CMP> pq;

int n;
char s[1005][25];
char ans[1005][2005];

NODE* newNode(long long w, int id, NODE* l, NODE* r) {
    NODE* p = new NODE();
    p->w = w;
    p->id = id;
    p->l = l;
    p->r = r;
    return p;
}

void dfs(NODE* root, char path[], int depth) {
    if (!root) return;

    if (!root->l && !root->r) {
        path[depth] = '\0';
        strcpy(ans[root->id], path);
        return;
    }

    path[depth] = '0';
    dfs(root->l, path, depth + 1);

    path[depth] = '1';
    dfs(root->r, path, depth + 1);
}

int main() {
    scanf("%d", &n);

    if (n == 1) {
        long long w;
        scanf("%s %lld", s[0], &w);
        printf("%s 0\n", s[0]);
        return 0;
    }

    for (int i = 0; i < n; i++) {
        long long w;
        scanf("%s %lld", s[i], &w);
        pq.push(newNode(w, i, NULL, NULL));
    }

    while (pq.size() > 1) {
        NODE* a = pq.top(); pq.pop();
        NODE* b = pq.top(); pq.pop();

        pq.push(newNode(a->w + b->w, -1, a, b));
    }

    NODE* root = pq.top();

    char path[2005];
    dfs(root, path, 0);

    for (int i = 0; i < n; i++) {
        printf("%s %s\n", s[i], ans[i]);
    }

    return 0;
}
```

### 2.2 P1094 [NOIP 2007 普及组] 纪念品分组

**题目链接**：https://www.luogu.com.cn/problem/P1094

**知识点**：贪心、排序、双指针

**题目简述**：

> 把 $n$ 件价格分别为 $P_i$ 的纪念品分组，每组最多 $2$ 件，且每组价格之和不超过上限 $w$，求最少的分组数。
>
> 数据范围：$1\le n\le 3\times 10^4$，$80\le w\le 200$，$5\le P_i\le w$。

#### 详细分析

**1. 读题**

每组至多 2 件、组内和 $\le w$，要让组数最少——等价于让「两件配成一组」的情况尽可能多。

**2. 性质观察**

**贪心策略**：先将价格升序排序，再用双指针从两端向中间靠拢。每次考虑当前最贵的物品（右指针 `right`）：

- 若它能和当前最便宜的物品（左指针 `left`）凑成一组（和 $\le w$），就把两件配成一组，`left++`、`right--`；
- 否则最贵的物品只能单独成组，`right--`。

无论哪种情况组数 `zu++`。这样保证最贵的物品总能搭上一个尽量便宜的物品，是分组数最少的最优解。

**边界**：当 `left == right` 时还剩最后一件物品落单，需单独成一组（`zu++`）。

**3. 数据结构与算法选择**

- 数组 `gift[]` 存价格，`sort` 升序排序；
- 双指针 `left`、`right` 从两端扫描；
- 计数器 `zu`。

**4. 程序设计**

1. 读入上限 $w$、件数 $n$ 与各价格，升序排序；
2. `left=0, right=n-1`，当 `left < right`：
   - 若 `gift[left]+gift[right] > w`：仅最贵的单独成组，`right--`，`zu++`；
   - 否则两件成组，`left++`、`right--`，`zu++`；
3. 若 `left == right` 还剩一件，`zu++`；
4. 输出 `zu`。

**5. 时空复杂度分析**

排序 $O(n\log n)$，双指针扫描 $O(n)$，总时间 $O(n\log n)$，空间 $O(n)$。$n\le 3\times 10^4$ 可以通过。

#### 省流版

贪心 + 双指针。价格升序排序后，最贵的物品尝试与最便宜的物品配对：能配（和 $\le w$）则两件一组、双指针内移；不能配则最贵的单独成组、右指针内移。每步组数 +1，注意中间剩一件要单独成组。时间复杂度 $O(n\log n)$。

#### 代码实现

![AC截图](./P1094/P1094AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <queue>
#include <stack>
#include <string>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int gift[30004];

int main(){
	int n, w;
	int left, right;
	int zu = 0;

	scanf("%d", &w);
	scanf("%d", &n);
	for(int i = 0; i < n; i++){
		scanf("%d", &gift[i]);
	}

	left = 0;
	right = n - 1;
	sort(gift, gift + n);

	while(left < right){
		if(gift[left] + gift[right] > w){
			right--;
			zu++;
		}else{
			left++;
			right--;
			zu++;
		}
	}

	if(left == right){
		zu++;
	}

	printf("%d\n", zu);
}
```

### 2.3 P1546 [USACO3.1] 最短网络 Agri-Net

**题目链接**：https://www.luogu.com.cn/problem/P1546

**知识点**：最小生成树、Prim 算法

**题目简述**：

> 已知 N 个农场的连接费用矩阵（对称），求连接所有农场所需的最小光纤长度。
>
> 数据范围：$3 \le N \le 100$。

#### 详细分析

1. 读题：给定一个 N×N 的完全带权图矩阵，求解使所有节点连通的最小生成树权值。

2. 性质观察：
   - 费用矩阵对称（无向图）
   - 对角线为 0（自己到自己不需要连接）
   - 求最小生成树的总权值

3. 程序设计：
   - 初始化 `smalltree` 数组为从节点 0 到各个节点的距离
   - 循环 N-1 次，每次找到距离最小的节点加入生成树
   - 加入节点后，更新其他节点到生成树的最小距离

4. 算法选择：Prim 算法（从节点 0 出发逐步构建最小生成树）

5. 时空复杂度：
   - 时间复杂度：$O(N^2)$
   - 空间复杂度：$O(N^2)$ 存储矩阵 + $O(N)$ 辅助数组

#### 省流版

使用 Prim 算法求解最小生成树。从节点 0 开始，每次选择到已选集合距离最小的节点加入，并更新其他节点的距离。循环 N-1 次即可得到最小生成树的总权值。

#### 代码实现

![AC截图](./P1546/P1546AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>
#include <queue>
#include <stack>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int ditu[110][110];
int smalltree[110];

int find_small(int n){
    int dp = 0;
    int min = 0x7FFFFFFF;

    for(int i = 0; i<n; i++){
        if(smalltree[i] == 0){
            continue;
        }
        if(smalltree[i] < min){
            min = smalltree[i];
            dp = i;
        }
    }

    return dp;
}

int main(){
    memset(smalltree, 0x7F, sizeof(smalltree));

    int n;
    int chang = 0;
    int nextpo;

    scanf("%d", &n);
    for(int i = 0; i < n; i++){
        for(int j = 0; j < n; j++){
            scanf("%d", &ditu[i][j]);
        }
    }
    for(int i = 0; i<n; i++){
        smalltree[i] = ditu[0][i];
    }

    for(int j = 1; j < n; j++){
        nextpo = find_small(n);
        chang += smalltree[nextpo];
        smalltree[nextpo] = 0;
        for(int i = 0; i < n; i++){
            if(smalltree[i] > ditu[nextpo][i]){
                smalltree[i] = ditu[nextpo][i];
            }
        }
    }


    printf("%d\n", chang);

}
```

### 2.4 P1803 凌乱的 yyy / 线段覆盖

**题目链接**：https://www.luogu.com.cn/problem/P1803

**知识点**：贪心、区间调度

**题目简述**：

> 有 $n$ 个比赛，第 $i$ 个的起止时间为 $[a_i, b_i)$。参加比赛必须善始善终，且任意两场不能在时间上重叠。求最多能参加多少场比赛。
>
> 数据范围：$1\le n\le 10^6$，$0\le a_i<b_i\le 10^6$。

#### 详细分析

**1. 读题**

经典的「最多不相交区间」（活动选择）问题。$n$ 达 $10^6$，需要 $O(n\log n)$ 的排序贪心。

**2. 性质观察**

贪心核心：**让已选比赛的结束时间尽可能早**，就能给后面留出更多空间。本代码采用「按开始时间排序 + 维护当前已选的最早结束时间 `lastend`」的等价实现：

- 遍历到一个比赛 $[a,b)$，若 `a >= lastend`，说明它与已选的不冲突，选它，`lastend = b`，计数 +1；
- 若冲突（`a < lastend`），则**不增加计数**，但如果当前比赛结束更早（`b < lastend`），就把已选的那场「替换」成它（更新 `lastend = b`），为后续腾出更早的结束时间。

这与「按结束时间排序后顺序贪心」是等效的，都保证每一步占用的结束时间最小，从而选出最多比赛。

**3. 数据结构与算法选择**

- `vector<pair<int,int>>` 存 $(a,b)$，按 pair 默认序（先 $a$ 后 $b$）排序；
- 变量 `lastend` 记录当前方案最后一场的结束时间，`ge` 记录已选场数。

**4. 程序设计**

1. 读入 $n$ 个区间 $(a,b)$，按开始时间排序；
2. `lastend=0, ge=0`，遍历每个区间：
   - 若 `a >= lastend`：选它，`ge++`，`lastend=b`；
   - 否则若 `b < lastend`：替换为更早结束者，`lastend=b`；
3. 输出 `ge`。

**5. 时空复杂度分析**

排序 $O(n\log n)$，扫描 $O(n)$，总时间 $O(n\log n)$，空间 $O(n)$。$n\le 10^6$ 可以通过。

#### 省流版

最多不相交区间贪心。按开始时间排序，维护已选方案的最早结束时间 `lastend`：不冲突就选（计数 +1 并更新结束时间），冲突时若当前结束更早就替换 `lastend`。本质是让占用的结束时间始终最小，从而选最多。时间复杂度 $O(n\log n)$。

#### 代码实现

![AC截图](./P1803/P1803AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <queue>
#include <stack>
#include <string>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

vector<pair<int, int>> bisai;

int main(){
	int a, b;
	int n;
	int lastend = 0;
	int ge = 0;

	scanf("%d", &n);
	for(int i = 0; i < n; i ++){
		scanf("%d%d", &a, &b);
		bisai.push_back({a, b});
	}

	sort(bisai.begin(), bisai.end());

	for(auto& it : bisai){
		a = it.first;
		b = it.second;

		if(a >= lastend){
			ge++;
			lastend = b;
			continue;
		}

		if(b < lastend){
			lastend = b;
		}
	}

	printf("%d\n", ge);
}
```

### 2.5 P2700 [JSOI2010] 逐个击破

**题目链接**：https://www.luogu.com.cn/problem/P2700

**知识点**：并查集、最大生成树（贪心）

**题目简述**：

> 给定一棵 N 个节点的树，K 个城市被敌方军团占领。每条边有权值 c，表示破坏该道路的代价。需要切断所有被占领城市之间的联系，求最小的破坏代价总和。
>
> 数据范围：$2 \le N \le 10^5$，$2 \le K \le N$，$1 \le c \le 10^6$。

#### 详细分析

1. **读题**：N 个城市构成一棵树，K 个城市被占领。破坏道路有代价，需要让所有被占领城市互相隔离。

2. **逆向思维**：与其直接求最小破坏代价，不如反过来思考——假设所有边都被保留，我们只需要"放弃"一些边使得被占领城市互相隔离。放弃的边权之和即为答案。

3. **贪心策略**：要让保留的边权最大，从而使得破坏的边权最小。将所有边按权值从大到小排序，依次处理每条边 $(u, v, w)$：
   - 若 $u$ 和 $v$ 已经在同一个连通块中，跳过（不需要这条边）
   - 若两个连通块中**都包含**被占领城市，则这条边必须被破坏，累加其代价
   - 否则，将两个连通块合并，并继承占领状态

4. **实现**：使用并查集维护连通块，用 `zhan[i]` 标记连通块是否包含被占领城市。

#### 省流版

将所有边按权值从大到小排序，用并查集依次连接城市。若连接时发现两边都已占领（在同一连通块且都有敌军），则该边必须破坏，累加其代价。

#### 代码实现

![AC截图](./P2700/P2700AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <queue>
#include <stack>
#include <vector>
#include <algorithm>

using namespace std;

int bingchaji[100010];
int zhan[100010]; //被占领的城市，1表示被占领

void init(int n){
    for(int i = 0; i < n; i++){
        bingchaji[i] = i;
    }
}

int find(int a){
    int s = bingchaji[a];
    while(s != bingchaji[s]){
        s = bingchaji[s];
    }
    bingchaji[a] = s;
    return s;
}

void memge(int a, int b){
    if(zhan[find(a)] || zhan[find(b)]){
        zhan[find(a)] = 1;
        zhan[find(b)] = 1;
    }
    bingchaji[find(a)] = find(b);
}

        memge(a, b);
```

### 2.6 P3366 【模板】最小生成树

**题目链接**：https://www.luogu.com.cn/problem/P3366

**知识点**：最小生成树、并查集、Kruskal 算法

**题目简述**：

> 给定一个含 N 个节点和 M 条边的无向图，求该图的最小生成树（MST）。若图不连通则输出 `orz`。
>
> 数据范围：$1 \le N \le 5000$，$1 \le M \le 2 \times 10^5$。

#### 详细分析

1. **读题**：本题要求求解无向图的最小生成树。最小生成树是指在一个带权无向图中，选取恰好 N-1 条边使得所有节点连通，且总权值最小。如果无法连通所有节点，则输出 `orz`。

2. **性质观察**：本题可以使用经典的 Kruskal 算法求解。

3. **程序设计**：
   - 读取 N 和 M
   - 读取 M 条边的信息（起点、终点、权值），存入边集合
   - 将所有边按权值升序排序
   - 依次遍历排序后的边，使用并查集检查边的两端是否已在同一连通分量中
   - 若不在，则选择该边加入最小生成树，并将两节点合并
   - 选取足够 N-1 条边后，输出总权值；若无法选够 N-1 条边，输出 `orz`

4. **数据结构与算法选择**：
   - 使用并查集（Union-Find）实现 Kruskal 算法
   - 并查集支持路径压缩
   - 对边按权值排序：时间复杂度 $O(M \log M)$

5. **时空复杂度分析**：
   - 时间复杂度：$O(M \log M)$ （排序） + $O(M \alpha(N))$ （并查集操作）
   - 空间复杂度：$O(N + M)$

#### 省流版

使用 Kruskal 算法求解最小生成树：将 M 条边按权值升序排序，依次选择不构成环的边加入生成树，若最终选够 N-1 条边则输出总权值，否则输出 `orz`。

### 2.7 P4047 [JSOI2010] 部落划分

**题目链接**：https://www.luogu.com.cn/problem/P4047

**知识点**：并查集、最小生成树、Kruskal

**题目简述**：

> 有 n 个野人居住点，给每个点分配一个部落标签，要求恰好划分为 k 个部落。定义两个部落的距离为两部落中距离最近的两点间距离。求一种划分方式，使得最近的两个部落距离尽可能大，输出这个最大距离。
>
> 数据范围：$2 \le k \le n \le 10^3$。

#### 详细分析

1. **读题**：n 个平面点，需要划分为恰好 k 个部落。目标是最小化"最近两个部落的距离"中的最大值——即最大化最近部落间距离的下界。

2. **性质观察**：本题等价于求最小生成树（MST）。将所有 n 个点看作图的顶点，任意两点间边的权值为欧氏距离。当我们用 Kruskal 算法构造 MST 时，依次加入最短的边并合并连通块，直到只剩 k 个连通块。此时最后加入的那条边的权值即为答案。

3. **程序设计**：
   - 预处理所有点对距离，共 n(n-1)/2 条边
   - 使用并查集维护部落划分
   - 依次合并距离最近的两个部落
   - 合并 n-k 次后，答案为当前最小部落间距离

4. **数据结构与算法选择**：
   - 并查集：高效合并与查询部落归属
   - 边表：存储所有点对距离
   - Kruskal 思想：每次找最小边合并，直到剩 k 个集合

5. **时空复杂度分析**：
   - 时间：$O(n^2)$ 建图 + $O(n^2)$ 合并过程 = $O(n^2)$
   - 空间：$O(n^2)$ 距离矩阵

#### 省流版

将 n 个点用并查集不断合并成 k 个部落，每次合并距离最近的两个部落。合并 n-k 次后，当前最小的部落间距离即为答案。本质是 Kruskal 构造最小生成树到只剩 k 条边。

#### 代码实现

![AC截图](./P4047/P4047AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>
#include <vector>
#include <stack>
#include <queue>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int bingchaji[1010];
double dist[1010][1010];
int px[1010];
int py[1010];

void init(int n){
    for(int i = 0; i < n; i++){
        bingchaji[i] = i;
    }
}

int find(int a){
    int s = bingchaji[a];
    while(s != bingchaji[s]){
        s = bingchaji[s];
    }
    bingchaji[a] = s;
    return s;
}

void memgre(int a, int b){
    bingchaji[b] = find(a);
}

void find_min(int n, int* a, int* b){
    double mind = 10e6;
    for(int i = 0; i < n; i++){
        if(find(i) != i) continue;
        for(int j = 0; j < n; j++){
            if(dist[i][j] == 0) continue;
            if(dist[i][j] < mind){
                mind = dist[i][j];
                *a = i;
                *b = j;
            }
        }
    }
    return;
}

double find_min_dist(int n){
    double mind = 10e6;
    for(int i = 0; i < n; i++){
        if(find(i) != i) continue;
        for(int j = 0; j < n; j++){
            if(dist[i][j] == 0) continue;
            if(dist[i][j] < mind){
                mind = dist[i][j];
            }
        }
    }
    return mind;
}

void memgre_buluo(int n){
    int a, b;
    find_min(n, &a, &b);
    memgre(a, b);
    for(int i = 0; i < n; i++){
        if(dist[a][i] > dist[b][i]){
            dist[a][i] = dist[b][i];
            dist[i][a] = dist[a][i];
        }
    }
}

int main(){
    int n, k;
    scanf("%d%d", &n, &k);
    for(int i = 0; i < n; i++){
        scanf("%d%d", &px[i], &py[i]);
    }
    for(int i = 0; i < n; i++){
        for(int j = 0; j < n; j++){
            dist[i][j] = hypot(px[i] - px[j], py[i] - py[j]);
        }
    }

    init(n);
    for(int i = 0; i < n - k; i++){
        memgre_buluo(n);
    }

    printf("%.2lf\n", find_min_dist(n));
    return 0;
}
```

### 2.8 P4053 [JSOI2007] 建筑抢修

**题目链接**：https://www.luogu.com.cn/problem/P4053

**知识点**：贪心、优先队列（带反悔贪心）

**题目简述**：

> 有 n 个建筑需要修理，每个建筑 i 有两个属性：修理时间 T1 和报废时间 T2。如果在 T2 时刻之前没有完成修理，建筑就会报废（刚好在 T2 时刻完成不会报废）。求最多能修理好的建筑数量。
>
> 数据范围：$1 \le n \le 150000$。

#### 详细分析

1. **读题**：n 个建筑，每个有修理时间 T1 和报废时间 T2。同一时刻只能修理一个建筑，求能修理的最大数量。

2. **性质观察**：
   - 报废时间越早的建筑越紧迫，应该优先处理 —— 按 T2 升序排序
   - 当处理到某个建筑发现时间不够时，可以考虑用较短的修理时间替换已选中的较长修理时间
   - 用最大堆维护已选中建筑的修理时间，可以快速找到并替换最长的一项

3. **程序设计**：
   - 按报废时间 T2 升序排序所有建筑
   - 维护当前已用时间 `time` 和最大堆 `built`（存储已选建筑的 T1）
   - 遍历每个建筑：
     - 将当前建筑的 T1 加入堆，`time += T1`
     - 若 `time > T2`，说明无法按时完成，将堆顶（最大 T1）弹出，`time -= 弹出值`
   - 最终堆的大小即为答案

4. **数据结构与算法选择**：
   - `priority_queue` 实现最大堆，维护已选建筑的修理时间
   - 时间复杂度 $O(n \log n)$，空间复杂度 $O(n)$

5. **时空复杂度分析**：
   - 时间：排序 $O(n \log n)$ + 遍历 $O(n \log n)$ = $O(n \log n)$
   - 空间：堆中最多存储 n 个元素，$O(n)$

#### 省流版

按报废时间排序，依次处理每个建筑，用最大堆维护已选建筑的修理时间。当时间超出当前建筑的报废时间时，弹出堆中最大的修理时间进行替换（相当于反悔），最终堆的大小即为最多能修理的建筑数。

#### 代码实现

![AC截图](./P4053/P4053AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <queue>
#include <vector>
#include <algorithm>

using namespace std;

auto cmp = [](auto &a, auto &b) {
    if (a.second == b.second) {
        return a.first > b.first;
    } else {
        return a.second > b.second;
    }
};
priority_queue<pair<long long int, long long int>, vector<pair<long long int, long long int>>, decltype(cmp)> building(cmp);

auto cmp2 = [](auto &a, auto &b) {
    return a.first < b.first;
};
priority_queue<pair<long long int, long long int>, vector<pair<long long int, long long int>>, decltype(cmp2)> built(cmp2);

int main() {
    long long int n;
    long long int s = 0;
    long long int t1, t2;
    long long int time = 0;

    scanf("%lld", &n);
    for (long long int i = 0; i < n; i++) {
        scanf("%lld%lld", &t1, &t2);
        building.push({t1, t2});
    }

    while (!building.empty()) {
        t1 = building.top().first;
        t2 = building.top().second;
        building.pop();

        if (time + t1 <= t2) {
            s++;
            time += t1;
            built.push({t1, t2});
        } else {
            if (t1 < built.top().first) {
                time -= built.top().first;
                time += t1;
                building.push(built.top());
                built.pop();
                built.push({t1, t2});
            }
        }
    }

    printf("%lld\n", s);
}
```

### 2.9 P5019 [NOIP 2018 提高组] 铺设道路

**题目链接**：https://www.luogu.com.cn/problem/P5019

**知识点**：贪心、差分思想

**题目简述**：

> 一条道路由 $n$ 块连续区域组成，第 $i$ 块下陷深度为 $d_i$。每天可选一段连续区间 $[L,R]$，将区间内每块区域的下陷深度各减 $1$（要求操作时区间内每块深度均 $>0$）。求把所有区域填平所需的最少天数。
>
> 数据范围：$1\le n\le 10^5$，$0\le d_i\le 10^4$。

#### 详细分析

**1. 读题**

每天能把一段连续区间整体「下降」$1$。要把整个高度数组削平到 $0$，求最少操作天数。

**2. 性质观察**

**关键贪心结论**：从左到右考虑，答案 = $d_1 + \sum_{i=2}^{n}\max(0,\,d_i-d_{i-1})$。

直观理解：相邻两块比较，

- 若 $d_i > d_{i-1}$，高出的部分 $d_i-d_{i-1}$ 必须用新的操作来填，无法蹭到左边的区间；累加这部分增量；
- 若 $d_i \le d_{i-1}$，当前这一块可以「搭便车」——填左边时顺带把它也填了，不需要新增天数。

这正是「正差分之和」，等价于把高度折线中所有**上升沿**的高度累加起来。

**3. 数据结构与算法选择**

无需存储整个数组，只需在线读入：维护前一块高度 `hight`，逐块累加上升量。

**4. 程序设计**

1. `day=0, hight=0`；
2. 逐块读入 `road`：若 `road > hight`，则 `day += road - hight`；
3. 更新 `hight = road`；
4. 输出 `day`。

**5. 时空复杂度分析**

单次线性扫描，时间复杂度 $O(n)$，空间 $O(1)$。$n\le 10^5$ 可以通过。

#### 省流版

贪心 / 差分。答案等于高度折线所有上升沿之和：从左到右，只要当前块比前一块高，就把高出的部分累加到天数；不高于则可蹭前面的操作。时间复杂度 $O(n)$，空间 $O(1)$。

#### 代码实现

![AC截图](./P5019/P5019AC.png)

```cpp

#include <stdlib.h>
#include <string.h>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <queue>
#include <stack>
#include <string>
#include <algorithm>

			day += road - hight;
		}
		hight = road;
	}

	printf("%d\n", day);
```

## 三、算法思想总结

### 3.1 本章核心算法思想

#### 贪心算法的基本思想

贪心算法（Greedy Algorithm）在每一步决策时都选择当前看起来最优的选项，希望通过局部最优的累积达到全局最优。贪心算法要正确应用，通常需要满足两个条件：
- **贪心选择性质**：全局最优可以通过一系列局部最优选择得到；
- **最优子结构**：问题的最优解包含子问题的最优解。

在本题单中，每一道题都体现了不同的贪心策略。

#### 各类贪心策略总结

**1. 哈夫曼贪心**

- **B2168 哈夫曼编码**：每次合并权值最小的两个节点，使高频词编码最短。贪心最优性可通过交换论证证明。

**2. 排序 + 双指针 / 区间调度**

- **P1094 纪念品分组**：排序后双指针配对，让贵的尽量与便宜的配对，减少单独成组。
- **P1803 线段覆盖**：按结束时间（或等价的开始时间替换策略）选择活动，使剩余时间最大化。

**3. 最小/最大生成树**

- **P1546 Agri-Net（Prim）**：每次选择距已选集合最近的点加入，逐步扩展生成树。
- **P3366 最小生成树（Kruskal）**：按边权从小到大选边，用并查集判环。
- **P4047 部落划分（Kruskal 扩展）**：合并到只剩 k 个集合，最后加入的边即为最大最近距离。
- **P2700 逐个击破（最大生成树思想）**：按边权从大到小保留边，两边都有占领城市时被迫破坏。

**4. 反悔贪心**

- **P4053 建筑抢修**：按截止时间排序，用最大堆维护已选任务。当时间超限时，弹出耗时最长的任务（反悔），用更短的任务替换。

**5. 差分贪心**

- **P5019 铺设道路**：把问题转化为高度折线的上升沿之和，每个上升沿对应一次新的操作。

### 3.3 常见解题模式与技巧

1. **哈夫曼问题**：看到「合并代价」、「编码长度 × 频次最小」等关键词，考虑哈夫曼树 + 小根堆。
2. **区间调度**：看到「最多不相交区间」、「最多活动数」等，考虑按结束时间排序贪心。
3. **生成树问题**：看到「连接所有点的最小代价」、「划分集合」等，考虑 Prim 或 Kruskal。
4. **反悔贪心**：当贪心过程中发现当前选择导致后续无法完成时，用堆维护已选元素，适时「反悔」替换。
5. **双指针**：排序后从两端向中间扫描，常用于配对、分组问题。
6. **差分/扫描**：看到「连续区间操作」、「填平高度」等，考虑相邻元素的差分关系。
7. **long long 的使用**：当权值累加可能很大时（如哈夫曼权值、生成树边权），使用 `long long`。
