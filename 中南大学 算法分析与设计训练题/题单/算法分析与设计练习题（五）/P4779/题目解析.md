# P4779 【模板】单源最短路径（标准版）

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P4779

知识点：图论、最短路、Dijkstra、优先队列

## 题目简述

> 给定一个 n 个点、m 条有向边的带非负权图，求从源点 s = 1 出发到每个点的最短距离。
>
> 数据范围：n ≤ 10⁵，m ≤ 2×10⁵。
>
> 时间限制：1S，空间限制：512MB。

## 题目分析

### 详细版

**1. 读题**

经典单源最短路模板题，图中有向、边权非负，适合使用 Dijkstra 算法。

**2. 性质观察**

Dijkstra 算法基于贪心思想：每次从未确定最短路的点中选择距离源点最近的点，用它更新邻居的距离。由于边权非负，一旦一个点被确定，其最短路不会再被更新。

**3. 数据结构与算法选择**

使用 **优先队列（小根堆）优化 Dijkstra**。朴素做法每次找最近点需要 O(n)，总复杂度 O(n²)；堆优化后每次取点和更新都是 O(log n)，总复杂度 O((n+m) log n)。

**4. 程序设计**

- 使用邻接表存图。
- dis[i] 表示源点到 i 的当前最短距离，初始为 INF，dis[s] = 0。
- vis[i] 标记是否已经确定最短路。
- 优先队列中存放 (距离, 节点)，每次取距离最小的节点。
- 若该节点已被访问则跳过；否则用它更新所有邻居的距离。
- 最后输出 dis[1..n]。

**5. 时空复杂度分析**

时间复杂度：O((n + m) log n)。
空间复杂度：O(n + m)。

### 省流版

堆优化 Dijkstra：小根堆维护当前最短距离，每次取最近点松弛邻居，直到所有点确定。

## 代码实现

![AC截图](./P4779AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

const long long INF = 0x3f3f3f3f3f3f3f3fLL;

int n, m, s;
vector<pair<int, int>> g[100010];
long long dis[100010];
int vis[100010];

struct State{
	int u;
	long long d;
	bool operator<(const State& other) const {
		return d > other.d;
	}
};

void dijkstra(){
	priority_queue<State> pq;
	memset(dis, 0x3f, sizeof(dis));
	dis[s] = 0;
	pq.push((State){s, 0});
	while(!pq.empty()){
		State cur = pq.top();
		pq.pop();
		int u = cur.u;
		if(vis[u]) continue;
		vis[u] = 1;
		for(int i = 0; i < (int)g[u].size(); i++){
			int v = g[u][i].first;
			int w = g[u][i].second;
			if(dis[u] + w < dis[v]){
				dis[v] = dis[u] + w;
				pq.push((State){v, dis[v]});
			}
		}
	}
}

int main(){
	scanf("%d%d%d", &n, &m, &s);
	for(int i = 0; i < m; i++){
		int u, v, w;
		scanf("%d%d%d", &u, &v, &w);
		g[u].push_back(make_pair(v, w));
	}

	dijkstra();

	for(int i = 1; i <= n; i++){
		printf("%lld ", dis[i]);
	}
	printf("\n");
}
```
