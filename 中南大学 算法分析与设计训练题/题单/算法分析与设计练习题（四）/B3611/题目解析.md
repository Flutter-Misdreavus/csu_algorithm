# B3611 【模板】传递闭包

## 题目信息

题目链接：https://www.luogu.com.cn/problem/B3611

知识点：图论、传递闭包、Floyd

## 题目简述

> 给定一张 n 个点的有向图的邻接矩阵 A，其中 a[i][j] = 1 表示 i 到 j 有直接连边，a[i][j] = 0 表示没有。求该图的传递闭包矩阵 B，即 b[i][j] = 1 当且仅当 i 可以直接或间接到达 j。
>
> 数据范围：1 ≤ n ≤ 100。
>
> 时间限制：1S，空间限制：128MB。

## 题目分析

### 详细版

**1. 读题**

传递闭包描述的是有向图中任意两点之间是否存在路径（包括直接和间接）。如果 i 能到达 k，且 k 能到达 j，那么 i 就能到达 j。

**2. 性质观察**

这与 Floyd 算法的精神完全一致。Floyd 通过中间点 k 松弛最短路，这里则是通过中间点 k 扩展可达性：

```
b[i][j] = b[i][j] OR (b[i][k] AND b[k][j])
```

只要存在某个中间点 k，使得 i 能到 k 且 k 能到 j，那么 i 就能到 j。

**3. 数据结构与算法选择**

使用二维布尔（或整数 0/1）数组存储邻接矩阵，直接在原矩阵上进行传递闭包计算。算法选择 **Floyd-Warshall 的布尔版本**。

**4. 程序设计**

- 读入 n 和邻接矩阵 a。
- 三重循环：枚举中间点 k，再枚举起点 i 和终点 j。
- 若 `a[i][k] == 1` 且 `a[k][j] == 1`，则令 `a[i][j] = 1`。
- 输出最终的传递闭包矩阵。

**5. 时空复杂度分析**

时间复杂度：三重循环，O(n³)。当 n = 100 时完全可行。
空间复杂度：邻接矩阵 O(n²)。

### 省流版

布尔版 Floyd：若 i 能到 k 且 k 能到 j，则 i 能到 j，直接输出闭包矩阵。

## 代码实现

![AC截图](./B3611AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int n;
int a[110][110];

int main(){
	scanf("%d", &n);
	for(int i = 0; i < n; i++){
		for(int j = 0; j < n; j++){
			scanf("%d", &a[i][j]);
		}
	}

	for(int k = 0; k < n; k++){
		for(int i = 0; i < n; i++){
			for(int j = 0; j < n; j++){
				if(a[i][k] && a[k][j]){
					a[i][j] = 1;
				}
			}
		}
	}

	for(int i = 0; i < n; i++){
		for(int j = 0; j < n; j++){
			printf("%d ", a[i][j]);
		}
		printf("\n");
	}
}
```
