## 写在前面

欢迎同学们学习算法分析与设计课程！

为了让同学们将理论与实践相结合的同时，锻炼代码能力，为以后的工作和科研奠定基础——我们为同学们精心准备了算法分析与设计练习题供同学们学习。

题目难度分级说明如下：

| 题目难度 | 说明                                                                      | 数量 |
| -------- | ------------------------------------------------------------------------- | ---- |
| EZ       | 基础题，学过 C 语言、数据结构，对对应的算法有一定了解就能做出来           | 34   |
| MID      | 简单应用题，所有人多想多调就能做出来                                      | 31   |
| MID-HARD | 认真学了，有一定的思维能力和代码能力，学过和熟练的分界线，对标前 40% 同学 | 16   |

相关附件可从对应课程 QQ 群下载。

## 学习要求

尽量独立地完成所有习题，不要过分依赖生成式大模型。

- 对于难度 EZ 和 MID 的习题，难度是所有人都可以秒杀/稍微努努力完成的，请所有同学完成。
- 对于难度 MID-HARD 的习题，有一定难度但是可以战胜，请同学们尽量挑战。
- 对于难度 HARD 的习题，供学有余力、想要挑战自我，感受数据结构和算法之美的同学扩展。
- 对于难度 ACM 的习题，供同学们开阔视野。

完成习题后，请撰写解题报告。参考给出的模板，对于每个题单，撰写一份解题报告（即总共需要提交三份解题报告），并注意在规定时间之前提交。

要求解题报告模板中的各个部分均要体现，请独立自主认真完成，不要过分依赖生成式大模型。

## 常见问题

### 洛谷怎么用？怎么注册账号？我交了题跳出来那个界面看不懂？……

OJ 使用问题，请自行解决，或与大语言模型交互。

### 我的代码为什么能过样例但是交上去不对？

说明你写的代码仅仅在给定样例这一种比较特殊的情况下运行正确，但在规模更大的、更复杂的情况下代码逻辑是错误的。问题包括但不限于：考虑的情况较少、代码计算次数过多运行效率过低、手抽有地方写错了……

如果一道题目有几千几万人过了但是您没过，那大概率是您的问题。请再三检查！
