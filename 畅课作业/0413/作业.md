## 题目

假设按照升序排序的数组在预先未知的某个点（K）上进行了旋转。如 [0,1,2,4,5,6,7] 可能变为 [4,5,6,7,0,1,2]，此时k = 4。请给出策略，输出旋转点k。

---

## 一、问题分析

原数组是严格升序（或非降序）排列的。在未知点 `k` 处旋转后，数组被分成两个连续的升序段：

- **前段**：`nums[0..k-1]`，由原数组的后 `n-k` 个元素组成，保持升序
- **后段**：`nums[k..n-1]`，由原数组的前 `k` 个元素组成，保持升序

由于原数组升序，旋转后**前段的任意元素都大于等于后段的任意元素**。旋转点 `k` 正是后段的第一个元素，也就是**整个数组的最小值所在下标**。

因此，问题转化为：在旋转后的数组中，找到最小值的下标。

---

## 二、算法策略：二分查找

若直接遍历数组找最小值，时间复杂度为 $O(n)$。但旋转后的数组具有特殊的分段单调性，可以利用**二分查找**将时间复杂度降至 $O(\log n)$。

### 核心观察

旋转后的数组虽然整体不单调，但由**两个升序段**拼接而成。这种结构使得我们可以通过比较中间元素与边界元素，判断最小值落在哪个半区，从而每次将搜索范围缩小一半。

---

## 三、核心思想与数学证明

### 3.1 关键引理

> **引理**：设当前搜索区间为 $[left, right]$，令 $mid = \left\lfloor \dfrac{left + right}{2} \right\rfloor$，则：
>
> 1. 若 $nums[mid] > nums[right]$，则最小值（旋转点）必在区间 $(mid, right]$ 中；
> 2. 若 $nums[mid] < nums[right]$，则最小值（旋转点）必在区间 $[left, mid]$ 中；
> 3. 若 $nums[mid] = nums[right]$，则 $nums[right]$ 不是唯一的最小值候选，可将 $right$ 减 1 缩小范围。

### 3.2 证明

**情形 1：$nums[mid] > nums[right]$**

由于数组由两个升序段组成，$nums[mid]$ 和 $nums[right]$ 的位置关系只有两种可能：
- 两者都在前段：则 $nums[mid] < nums[right]$（前段升序），与条件矛盾；
- 两者都在后段：则 $nums[mid] < nums[right]$（后段升序），与条件矛盾；
- $nums[mid]$ 在前段，$nums[right]$ 在后段：则 $nums[mid] \geq$ 前段首元素 $>$ 后段末元素 $\geq nums[right]$，满足条件。

因此，$mid$ 位于前段，$right$ 位于后段，最小值（后段首元素）必然在 $mid$ 右侧，即区间 $(mid, right]$ 中。故令 $left = mid + 1$。

**情形 2：$nums[mid] < nums[right]$**

同理分析：
- 若 $nums[mid]$ 在前段、$nums[right]$ 在后段：则 $nums[mid] \geq$ 前段首元素 $>$ 后段末元素。由于 $nums[right]$ 在后段，$nums[right] \leq$ 后段末元素，故 $nums[mid] > nums[right]$，与条件矛盾；
- 若两者都在前段：则 $nums[mid] < nums[right]$（升序），但最小值在后段，不在 $[left, mid]$？

重新分析：若两者都在前段且 $nums[mid] < nums[right]$，则 $mid < right$ 且前段升序，这意味着 $mid$ 到 $right$ 都在前段。但此时最小值（后段首元素）位于 $mid$ 左侧，不在 $[left, mid]$ 中。

修正：若 $nums[mid] < nums[right]$，则 $mid$ 和 $right$ 必在同一段升序区间内。由于 $mid < right$，若它们在前段，则最小值在更左侧；若它们在后段，则最小值就是后段首元素，且在 $[left, mid]$ 中（因为后段从某处开始到 $mid$ 都是升序的）。

更严谨的论证：由于 $nums[mid] < nums[right]$，说明从 $mid$ 到 $right$ 是**递增**的，因此这段区间内不存在"断崖"（即旋转边界）。旋转边界（最小值）要么在 $mid$ 左侧（含 $mid$），要么不存在（整个区间单调）。由于旋转数组必存在旋转边界，故最小值在 $[left, mid]$ 中。令 $right = mid$。

**情形 3：$nums[mid] = nums[right]$**

此时无法确定 $mid$ 和 $right$ 是否在同一段。但它们值相等，说明 $nums[right]$ 即使是最小值，也不是唯一的。将 $right$ 减 1 不会丢失最小值（因为 $nums[mid]$ 与之相等，若 $nums[right]$ 是唯一最小值，则 $nums[mid]$ 也是）。故令 $right = right - 1$。

### 3.3 循环不变式与正确性

> **循环不变式**：在每次 `while (left < right)` 循环开始时，旋转点 $k$ 始终满足 $left \leq k \leq right$。

**初始化**：初始时 $left = 0, right = n - 1$，显然 $k \in [0, n-1]$，不变式成立。

**保持**：根据上述引理的三种情形：
- 情形 1：$k \in (mid, right]$，而 $left$ 更新为 $mid + 1$，故 $k \in [left', right]$；
- 情形 2：$k \in [left, mid]$，而 $right$ 更新为 $mid$，故 $k \in [left, right']$；
- 情形 3：$right$ 更新为 $right - 1$。由于 $nums[mid] = nums[right]$，若 $k = right$，则 $nums[k] = nums[mid]$，且 $mid < right$，说明 $mid$ 也在后段，故 $k \leq mid \leq right - 1 = right'$。

不变式保持成立。

**终止**：当循环结束时，$left = right$。由不变式知 $k \in [left, left]$，即 $k = left$。返回 $left$ 即为正确答案。

## 四、算法步骤（伪代码）

```
函数 findRotatePoint(nums):
    n = nums的长度
    如果 n == 0: 返回 -1
    如果 n == 1: 返回 0

    left = 0
    right = n - 1

    当 left < right 时:
        mid = left + (right - left) / 2

        如果 nums[mid] > nums[right]:
            left = mid + 1
        否则如果 nums[mid] < nums[right]:
            right = mid
        否则:
            right = right - 1

    返回 left
```

---

## 五、复杂度分析

| 复杂度类型 | 值 | 说明 |
|-----------|-----|------|
| **时间复杂度** | $O(\log n)$（平均）/ $O(n)$（最坏） | 每次至少将区间减半；最坏情况（所有元素相等）每次只减 1 |
| **空间复杂度** | $O(1)$ | 仅使用常数个额外变量（left, right, mid）|

- **最优情况**：第一次比较就确定半区，严格 $O(\log n)$。
- **最坏情况**：数组中所有元素相等（如 `[1,1,1,1]`），每次只能将 `right` 减 1，退化到 $O(n)$。

## 六、参考实现（C++）

```cpp
#include <bits/stdc++.h>
using namespace std;

int findRotatePoint(vector<int>& nums) {
    int n = nums.size();
    if (n == 0) return -1;
    if (n == 1) return 0;

    int left = 0, right = n - 1;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] > nums[right]) {
            left = mid + 1;
        } else if (nums[mid] < nums[right]) {
            right = mid;
        } else {
            right--;
        }
    }
    return left;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n)) return 0;
    vector<int> nums(n);
    for (int i = 0; i < n; ++i) {
        cin >> nums[i];
    }

    int k = findRotatePoint(nums);
    cout << k << endl;

    return 0;
}
```

## 七、示例分析

以题目中的例子 `[4,5,6,7,0,1,2]` 为例：

| 轮次 | left | right | mid | nums[mid] | nums[right] | 判断 | 操作 |
|------|------|-------|-----|-----------|-------------|------|------|
| 1 | 0 | 6 | 3 | 7 | 2 | 7 > 2 | left = 4 |
| 2 | 4 | 6 | 5 | 1 | 2 | 1 < 2 | right = 5 |
| 3 | 4 | 5 | 4 | 0 | 1 | 0 < 1 | right = 4 |
| 终止 | 4 | 4 | - | - | - | left == right | 返回 4 |

输出 `k = 4`，与题目一致。


**输出**

**输入**
```
4

```

```

```
