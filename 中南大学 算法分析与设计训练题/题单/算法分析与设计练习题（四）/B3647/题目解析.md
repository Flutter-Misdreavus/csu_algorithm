# B3647 【模板】Floyd

## 题目信息

题目链接：https://www.luogu.com.cn/problem/B3647

知识点：图论、最短路、Floyd-Warshall

## 题目简述

> 给定一张 n 个点 m 条边的无向连通图，图中可能存在重边。求所有点对 (i, j) 之间的最短路径长度。
>
> 数据范围：n ≤ 100，m ≤ 4500，1 ≤ w ≤ 1000。
>
> 时间限制：1S，空间限制：512MB。

## 题目分析

### 详细版

**1. 读题**

本题是 Floyd 算法模板题，要求计算无向带权图中任意两点间的最短距离，并输出完整的距离矩阵。

**2. 性质观察**

Floyd 算法基于动态规划思想，用 `dis[k][i][j]` 表示只经过前 k 个中间点，从 i 到 j 的最短距离。通过滚动数组优化后，使用 `dis[i][j]` 即可。核心状态转移方程为：

```
dis[i][j] = min(dis[i][j], dis[i][k] + dis[k][j])
```

即：经过中间点 k 是否能让 i 到 j 的路径更短。

**3. 数据结构与算法选择**

使用二维数组 `dis[i][j]` 记录从 i 到 j 的最短距离。算法选择 **Floyd-Warshall**，它适合求解所有点对最短路，时间复杂度为 O(n³)。由于 n ≤ 100，完全在可接受范围内。

**4. 程序设计**

- 初始化 `dis[i][j]` 为正无穷 `INF`，`dis[i][i] = 0`。
- 读入每条无向边 `(u, v, w)`，由于可能存在重边，保留权值最小的边：
  - `dis[u][v] = min(dis[u][v], w)`
  - `dis[v][u] = min(dis[v][u], w)`
- 执行三重循环的 Floyd 算法。
- 输出距离矩阵，每行 n 个整数。

**5. 时空复杂度分析**

时间复杂度：三重循环，O(n³)。当 n = 100 时约为 10⁶ 次运算。
空间复杂度：二维距离矩阵，O(n²)。

### 省流版

Floyd 模板：初始化距离矩阵为 INF，读入边取最小值，三重循环用中间点 k 松弛所有 `dis[i][j]`，最后输出距离矩阵。

## 代码实现

![AC截图](./B3647AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int n, m;
int dis[110][110];
const int INF = 0x3f3f3f3f;

int main(){
	scanf("%d%d", &n, &m);
	memset(dis, 0x3f, sizeof(dis));
	for(int i = 1; i <= n; i++){
		dis[i][i] = 0;
	}

	for(int i = 0; i < m; i++){
		int u, v, w;
		scanf("%d%d%d", &u, &v, &w);
		if(w < dis[u][v]){
			dis[u][v] = w;
			dis[v][u] = w;
		}
	}

	for(int k = 1; k <= n; k++){
		for(int i = 1; i <= n; i++){
			for(int j = 1; j <= n; j++){
				if(dis[i][k] + dis[k][j] < dis[i][j]){
					dis[i][j] = dis[i][k] + dis[k][j];
				}
			}
		}
	}

	for(int i = 1; i <= n; i++){
		for(int j = 1; j <= n; j++){
			printf("%d ", dis[i][j]);
		}
		printf("\n");
	}
}
```
