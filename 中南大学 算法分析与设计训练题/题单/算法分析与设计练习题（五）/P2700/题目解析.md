# P2700 逐个击破

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P2700

知识点：并查集、最大生成树（贪心）

## 题目简述

> 给定一棵 N 个节点（编号 0~N-1）的树，K 个城市被敌方军团占领。每条边有权值 c，表示破坏该道路的代价。需要切断所有被占领城市之间的联系，求最小的破坏代价总和。
>
> 数据范围：$2 \le N \le 10^5$，$2 \le K \le N$，$1 \le c \le 10^6$
>
> 时间限制：1S，空间限制：256MB

## 题目分析

### 详细版

1. **读题**：N 个城市构成一棵树，K 个城市被占领。破坏道路有代价，需要让所有被占领城市互相隔离。

2. **逆向思维**：与其直接求最小破坏代价，不如反过来思考——假设所有边都被保留，我们只需要"放弃"一些边使得被占领城市互相隔离。放弃的边权之和即为答案。

3. **贪心策略**：要让保留的边权最大，从而使得破坏的边权最小。将所有边按权值从大到小排序，依次处理每条边 $(u, v, w)$：
   - 若 $u$ 和 $v$ 已经在同一个连通块中，跳过（不需要这条边）
   - 若两个连通块中**都包含**被占领城市，则这条边必须被破坏，累加其代价
   - 否则，将两个连通块合并，并继承占领状态

4. **实现**：使用并查集维护连通块，用 `zhan[i]` 标记连通块是否包含被占领城市。

### 省流版

将所有边按权值从大到小排序，用并查集依次连接城市。若连接时发现两边都已占领（在同一连通块且都有敌军），则该边必须破坏，累加其代价。

## 代码实现

![AC截图](./P2700AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <queue>
#include <stack>
#include <vector>
#include <algorithm>

using namespace std;

int bingchaji[100010];
int zhan[100010]; //被占领的城市，1表示被占领

void init(int n){
    for(int i = 0; i < n; i++){
        bingchaji[i] = i;
    }
}

int find(int a){
    int s = bingchaji[a];
    while(s != bingchaji[s]){
        s = bingchaji[s];
    }
    bingchaji[a] = s;
    return s;
}

void memge(int a, int b){
    if(zhan[find(a)] || zhan[find(b)]){
        zhan[find(a)] = 1;
        zhan[find(b)] = 1;
    }
    bingchaji[find(a)] = find(b);
}

vector<pair<pair<int, int>, int>> bian;

int main(){
    int n, k;
    int city;
    int a, b, c;
    long long int daijiao = 0;
    memset(zhan, 0, sizeof(zhan));

    scanf("%d%d", &n, &k);
    for(int i = 0; i < k; i++){
        scanf("%d", &city);
        zhan[city] = 1;
    }
    for(int i = 0; i < n - 1; i++){
        scanf("%d%d%d", &a, &b, &c);
        bian.push_back({{a, b}, c});
    }

    sort(bian.begin(), bian.end(), [](auto &a, auto &b){
        return a.second > b.second; // 按权值从大到小排序
    });

    init(n);

    for(auto it = bian.begin(); it != bian.end(); it++){
        a = (*it).first.first;
        b = (*it).first.second;
        c = (*it).second;

        if(find(a) == find(b)){
            daijiao += c; // 同集合，边必须破坏
            continue;
        }

        if(zhan[find(a)] && zhan[find(b)]){
            daijiao += c; // 两边都有占领城市，必须破坏
            continue;
        }

        memge(a, b);
    }

    printf("%lld\n", daijiao);
}
```

## 时空复杂度

- **时间复杂度**：$O(N \log N)$，排序为主要开销
- **空间复杂度**：$O(N)$，存储边和并查集
