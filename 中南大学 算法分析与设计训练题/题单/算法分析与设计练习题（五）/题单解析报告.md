### 2.1 B2168 【模板】哈夫曼编码

**题目链接**：https://www.luogu.com.cn/problem/B2168

**知识点**：贪心、哈夫曼树、优先队列（小根堆）

**题目简述**：

> 给定 $n$ 个互不相同的单词及其频次 $w_i$，构造一种哈夫曼编码方案，使带权路径长度（$\sum$ 编码长度 $\times$ 频次）最小，输出任意一种合法方案，单词顺序与输入一致。
>
> 数据范围：$1\le n\le 1000$，$1\le w_i\le 10^9$。

#### 详细分析

**1. 读题**

哈夫曼编码模板。核心是构造哈夫曼树：频次越高的单词编码越短，从而使 WPL 最小。题目接受任意一种最优方案。

**2. 性质观察**

哈夫曼树的贪心构造：每次取出当前权值**最小的两个**节点合并成一个新节点（权值为两者之和），重复直到只剩一个根。合并时左分支记 $0$、右分支记 $1$，从根到叶子的路径即为该单词的编码。频次大的叶子离根近、编码短，保证 WPL 最小（贪心可证最优）。

**边界**：$n=1$ 时无法构成二叉树分支，需特判，直接给该单词编码 `0`。

**3. 数据结构与算法选择**

- 节点结构体 `NODE{w, id, l, r}`，叶子记录单词编号 `id`，内部节点 `id=-1`；
- **小根堆** `priority_queue`（比较器 `w` 升序）维护当前节点集合，每次弹出两个最小的合并；
- 建树完成后从根 DFS，沿左 $0$ 右 $1$ 累积路径字符串，到叶子时写入 `ans[id]`；
- 最后按输入顺序输出。

**4. 程序设计**

1. 特判 $n=1$：直接输出该单词与编码 `0`；
2. 读入 $n$ 个单词与频次，各建一个叶子节点入堆；
3. 当堆中节点数 $>1$：弹出两个最小节点 $a,b$，合并成 `newNode(a->w+b->w, -1, a, b)` 入堆；
4. 取根，`dfs(root, path, 0)`：到叶子写 `strcpy(ans[id], path)`，否则向左追加 `'0'`、向右追加 `'1'`；
5. 按输入顺序逐行输出单词及其编码。

**5. 时空复杂度分析**

建树需 $n-1$ 次合并，每次堆操作 $O(\log n)$，建树 $O(n\log n)$；DFS 遍历 $O(n\times\text{编码长度})$。$n\le 1000$ 可以通过。频次累加和达 $10^{12}$ 量级，权值用 `long long`。

#### 省流版

哈夫曼树贪心：小根堆每次取两个最小权值节点合并，直到剩一个根；左 $0$ 右 $1$，DFS 到叶子得到各单词编码。注意 $n=1$ 特判（编码记为 `0`），权值用 `long long`。建树 $O(n\log n)$。

#### 代码实现

![AC截图](./B2168/B2168AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <queue>
#include <vector>
#include <list>
#include <set>
#include <map>
#include <string>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

struct NODE {
    long long w;
    int id;          // 叶子编号，非叶子 = -1
    NODE *l, *r;
};

struct CMP {
    bool operator()(NODE* a, NODE* b) const {
        return a->w > b->w; // 小根堆
    }
};

priority_queue<NODE*, vector<NODE*>, CMP> pq;

int n;
char s[1005][25];
char ans[1005][2005];

NODE* newNode(long long w, int id, NODE* l, NODE* r) {
    NODE* p = new NODE();
    p->w = w;
    p->id = id;
    p->l = l;
    p->r = r;
    return p;
}

void dfs(NODE* root, char path[], int depth) {
    if (!root) return;

    if (!root->l && !root->r) {
        path[depth] = '\0';
        strcpy(ans[root->id], path);
        return;
    }

    path[depth] = '0';
    dfs(root->l, path, depth + 1);

    path[depth] = '1';
    dfs(root->r, path, depth + 1);
}

int main() {
    scanf("%d", &n);

    if (n == 1) {
        long long w;
        scanf("%s %lld", s[0], &w);
        printf("%s 0\n", s[0]);
        return 0;
    }

    for (int i = 0; i < n; i++) {
        long long w;
        scanf("%s %lld", s[i], &w);
        pq.push(newNode(w, i, NULL, NULL));
    }

    while (pq.size() > 1) {
        NODE* a = pq.top(); pq.pop();
        NODE* b = pq.top(); pq.pop();

        pq.push(newNode(a->w + b->w, -1, a, b));
    }

    NODE* root = pq.top();

    char path[2005];
    dfs(root, path, 0);

    for (int i = 0; i < n; i++) {
        printf("%s %s\n", s[i], ans[i]);
    }

    return 0;
}
```

### 2.2 P1094 [NOIP 2007 普及组] 纪念品分组

**题目链接**：https://www.luogu.com.cn/problem/P1094

**知识点**：贪心、排序、双指针

**题目简述**：

> 把 $n$ 件价格分别为 $P_i$ 的纪念品分组，每组最多 $2$ 件，且每组价格之和不超过上限 $w$，求最少的分组数。
>
> 数据范围：$1\le n\le 3\times 10^4$，$80\le w\le 200$，$5\le P_i\le w$。

#### 详细分析

**1. 读题**

每组至多 2 件、组内和 $\le w$，要让组数最少——等价于让「两件配成一组」的情况尽可能多。

**2. 性质观察**

**贪心策略**：先将价格升序排序，再用双指针从两端向中间靠拢。每次考虑当前最贵的物品（右指针 `right`）：

- 若它能和当前最便宜的物品（左指针 `left`）凑成一组（和 $\le w$），就把两件配成一组，`left++`、`right--`；
- 否则最贵的物品只能单独成组，`right--`。

无论哪种情况组数 `zu++`。这样保证最贵的物品总能搭上一个尽量便宜的物品，是分组数最少的最优解。

**边界**：当 `left == right` 时还剩最后一件物品落单，需单独成一组（`zu++`）。

**3. 数据结构与算法选择**

- 数组 `gift[]` 存价格，`sort` 升序排序；
- 双指针 `left`、`right` 从两端扫描；
- 计数器 `zu`。

**4. 程序设计**

1. 读入上限 $w$、件数 $n$ 与各价格，升序排序；
2. `left=0, right=n-1`，当 `left < right`：
   - 若 `gift[left]+gift[right] > w`：仅最贵的单独成组，`right--`，`zu++`；
   - 否则两件成组，`left++`、`right--`，`zu++`；
3. 若 `left == right` 还剩一件，`zu++`；
4. 输出 `zu`。

**5. 时空复杂度分析**

排序 $O(n\log n)$，双指针扫描 $O(n)$，总时间 $O(n\log n)$，空间 $O(n)$。$n\le 3\times 10^4$ 可以通过。

#### 省流版

贪心 + 双指针。价格升序排序后，最贵的物品尝试与最便宜的物品配对：能配（和 $\le w$）则两件一组、双指针内移；不能配则最贵的单独成组、右指针内移。每步组数 +1，注意中间剩一件要单独成组。时间复杂度 $O(n\log n)$。

#### 代码实现

![AC截图](./P1094/P1094AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <queue>
#include <stack>
#include <string>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int gift[30004];

int main(){
	int n, w;
	int left, right;
	int zu = 0;

	scanf("%d", &w);
	scanf("%d", &n);
	for(int i = 0; i < n; i++){
		scanf("%d", &gift[i]);
	}

	left = 0;
	right = n - 1;
	sort(gift, gift + n);

	while(left < right){
		if(gift[left] + gift[right] > w){
			right--;
			zu++;
		}else{
			left++;
			right--;
			zu++;
		}
	}

	if(left == right){
		zu++;
	}

	printf("%d\n", zu);
}
```

### 2.3 P1546 [USACO3.1] 最短网络 Agri-Net

**题目链接**：https://www.luogu.com.cn/problem/P1546

**知识点**：最小生成树、Prim 算法

**题目简述**：

> 已知 N 个农场的连接费用矩阵（对称），求连接所有农场所需的最小光纤长度。
>
> 数据范围：$3 \le N \le 100$。

#### 详细分析

1. 读题：给定一个 N×N 的完全带权图矩阵，求解使所有节点连通的最小生成树权值。

2. 性质观察：
   - 费用矩阵对称（无向图）
   - 对角线为 0（自己到自己不需要连接）
   - 求最小生成树的总权值

3. 程序设计：
   - 初始化 `smalltree` 数组为从节点 0 到各个节点的距离
   - 循环 N-1 次，每次找到距离最小的节点加入生成树
   - 加入节点后，更新其他节点到生成树的最小距离

4. 算法选择：Prim 算法（从节点 0 出发逐步构建最小生成树）

5. 时空复杂度：
   - 时间复杂度：$O(N^2)$
   - 空间复杂度：$O(N^2)$ 存储矩阵 + $O(N)$ 辅助数组

#### 省流版

使用 Prim 算法求解最小生成树。从节点 0 开始，每次选择到已选集合距离最小的节点加入，并更新其他节点的距离。循环 N-1 次即可得到最小生成树的总权值。

#### 代码实现

![AC截图](./P1546/P1546AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>
#include <queue>
#include <stack>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int ditu[110][110];
int smalltree[110];

int find_small(int n){
    int dp = 0;
    int min = 0x7FFFFFFF;

    for(int i = 0; i<n; i++){
        if(smalltree[i] == 0){
            continue;
        }
        if(smalltree[i] < min){
            min = smalltree[i];
            dp = i;
        }
    }

    return dp;
}

int main(){
    memset(smalltree, 0x7F, sizeof(smalltree));

    int n;
    int chang = 0;
    int nextpo;

    scanf("%d", &n);
    for(int i = 0; i < n; i++){
        for(int j = 0; j < n; j++){
            scanf("%d", &ditu[i][j]);
        }
    }
    for(int i = 0; i<n; i++){
        smalltree[i] = ditu[0][i];
    }

    for(int j = 1; j < n; j++){
        nextpo = find_small(n);
        chang += smalltree[nextpo];
        smalltree[nextpo] = 0;
        for(int i = 0; i < n; i++){
            if(smalltree[i] > ditu[nextpo][i]){
                smalltree[i] = ditu[nextpo][i];
            }
        }
    }


    printf("%d\n", chang);

}
```

### 2.4 P1803 凌乱的 yyy / 线段覆盖

**题目链接**：https://www.luogu.com.cn/problem/P1803

**知识点**：贪心、区间调度

**题目简述**：

> 有 $n$ 个比赛，第 $i$ 个的起止时间为 $[a_i, b_i)$。参加比赛必须善始善终，且任意两场不能在时间上重叠。求最多能参加多少场比赛。
>
> 数据范围：$1\le n\le 10^6$，$0\le a_i<b_i\le 10^6$。

#### 详细分析

**1. 读题**

经典的「最多不相交区间」（活动选择）问题。$n$ 达 $10^6$，需要 $O(n\log n)$ 的排序贪心。

**2. 性质观察**

贪心核心：**让已选比赛的结束时间尽可能早**，就能给后面留出更多空间。本代码采用「按开始时间排序 + 维护当前已选的最早结束时间 `lastend`」的等价实现：

- 遍历到一个比赛 $[a,b)$，若 `a >= lastend`，说明它与已选的不冲突，选它，`lastend = b`，计数 +1；
- 若冲突（`a < lastend`），则**不增加计数**，但如果当前比赛结束更早（`b < lastend`），就把已选的那场「替换」成它（更新 `lastend = b`），为后续腾出更早的结束时间。

这与「按结束时间排序后顺序贪心」是等效的，都保证每一步占用的结束时间最小，从而选出最多比赛。

**3. 数据结构与算法选择**

- `vector<pair<int,int>>` 存 $(a,b)$，按 pair 默认序（先 $a$ 后 $b$）排序；
- 变量 `lastend` 记录当前方案最后一场的结束时间，`ge` 记录已选场数。

**4. 程序设计**

1. 读入 $n$ 个区间 $(a,b)$，按开始时间排序；
2. `lastend=0, ge=0`，遍历每个区间：
   - 若 `a >= lastend`：选它，`ge++`，`lastend=b`；
   - 否则若 `b < lastend`：替换为更早结束者，`lastend=b`；
3. 输出 `ge`。

**5. 时空复杂度分析**

排序 $O(n\log n)$，扫描 $O(n)$，总时间 $O(n\log n)$，空间 $O(n)$。$n\le 10^6$ 可以通过。

#### 省流版

最多不相交区间贪心。按开始时间排序，维护已选方案的最早结束时间 `lastend`：不冲突就选（计数 +1 并更新结束时间），冲突时若当前结束更早就替换 `lastend`。本质是让占用的结束时间始终最小，从而选最多。时间复杂度 $O(n\log n)$。

#### 代码实现

![AC截图](./P1803/P1803AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <queue>
#include <stack>
#include <string>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

vector<pair<int, int>> bisai;

int main(){
	int a, b;
	int n;
	int lastend = 0;
	int ge = 0;

	scanf("%d", &n);
	for(int i = 0; i < n; i ++){
		scanf("%d%d", &a, &b);
		bisai.push_back({a, b});
	}

	sort(bisai.begin(), bisai.end());

	for(auto& it : bisai){
		a = it.first;
		b = it.second;

		if(a >= lastend){
			ge++;
			lastend = b;
			continue;
		}

		if(b < lastend){
			lastend = b;
		}
	}

	printf("%d\n", ge);
}
```

### 2.5 P2700 [JSOI2010] 逐个击破

**题目链接**：https://www.luogu.com.cn/problem/P2700

**知识点**：并查集、最大生成树（贪心）

**题目简述**：

> 给定一棵 N 个节点的树，K 个城市被敌方军团占领。每条边有权值 c，表示破坏该道路的代价。需要切断所有被占领城市之间的联系，求最小的破坏代价总和。
>
> 数据范围：$2 \le N \le 10^5$，$2 \le K \le N$，$1 \le c \le 10^6$。

#### 详细分析

1. **读题**：N 个城市构成一棵树，K 个城市被占领。破坏道路有代价，需要让所有被占领城市互相隔离。

2. **逆向思维**：与其直接求最小破坏代价，不如反过来思考——假设所有边都被保留，我们只需要"放弃"一些边使得被占领城市互相隔离。放弃的边权之和即为答案。

3. **贪心策略**：要让保留的边权最大，从而使得破坏的边权最小。将所有边按权值从大到小排序，依次处理每条边 $(u, v, w)$：
   - 若 $u$ 和 $v$ 已经在同一个连通块中，跳过（不需要这条边）
   - 若两个连通块中**都包含**被占领城市，则这条边必须被破坏，累加其代价
   - 否则，将两个连通块合并，并继承占领状态

4. **实现**：使用并查集维护连通块，用 `zhan[i]` 标记连通块是否包含被占领城市。

#### 省流版

将所有边按权值从大到小排序，用并查集依次连接城市。若连接时发现两边都已占领（在同一连通块且都有敌军），则该边必须破坏，累加其代价。

#### 代码实现

![AC截图](./P2700/P2700AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <queue>
#include <stack>
#include <vector>
#include <algorithm>

using namespace std;

int bingchaji[100010];
int zhan[100010]; //被占领的城市，1表示被占领

void init(int n){
    for(int i = 0; i < n; i++){
        bingchaji[i] = i;
    }
}

int find(int a){
    int s = bingchaji[a];
    while(s != bingchaji[s]){
        s = bingchaji[s];
    }
    bingchaji[a] = s;
    return s;
}

void memge(int a, int b){
    if(zhan[find(a)] || zhan[find(b)]){
        zhan[find(a)] = 1;
        zhan[find(b)] = 1;
    }
    bingchaji[find(a)] = find(b);
}

vector<pair<pair<int, int>, int>> bian;

int main(){
    int n, k;
    int city;
    int a, b, c;
    long long int daijiao = 0;
    memset(zhan, 0, sizeof(zhan));

    scanf("%d%d", &n, &k);
    for(int i = 0; i < k; i++){
        scanf("%d", &city);
        zhan[city] = 1;
    }
    for(int i = 0; i < n - 1; i++){
        scanf("%d%d%d", &a, &b, &c);
        bian.push_back({{a, b}, c});
    }

    sort(bian.begin(), bian.end(), [](auto &a, auto &b){
        return a.second > b.second; // 按权值从大到小排序
    });

    init(n);

    for(auto it = bian.begin(); it != bian.end(); it++){
        a = (*it).first.first;
        b = (*it).first.second;
        c = (*it).second;

        if(find(a) == find(b)){
            daijiao += c; // 同集合，边必须破坏
            continue;
        }

        if(zhan[find(a)] && zhan[find(b)]){
            daijiao += c; // 两边都有占领城市，必须破坏
            continue;
        }

        memge(a, b);
    }

    printf("%lld\n", daijiao);
}
```

### 2.6 P3366 【模板】最小生成树

**题目链接**：https://www.luogu.com.cn/problem/P3366

**知识点**：最小生成树、并查集、Kruskal 算法

**题目简述**：

> 给定一个含 N 个节点和 M 条边的无向图，求该图的最小生成树（MST）。若图不连通则输出 `orz`。
>
> 数据范围：$1 \le N \le 5000$，$1 \le M \le 2 \times 10^5$。

#### 详细分析

1. **读题**：本题要求求解无向图的最小生成树。最小生成树是指在一个带权无向图中，选取恰好 N-1 条边使得所有节点连通，且总权值最小。如果无法连通所有节点，则输出 `orz`。

2. **性质观察**：本题可以使用经典的 Kruskal 算法求解。

3. **程序设计**：
   - 读取 N 和 M
   - 读取 M 条边的信息（起点、终点、权值），存入边集合
   - 将所有边按权值升序排序
   - 依次遍历排序后的边，使用并查集检查边的两端是否已在同一连通分量中
   - 若不在，则选择该边加入最小生成树，并将两节点合并
   - 选取足够 N-1 条边后，输出总权值；若无法选够 N-1 条边，输出 `orz`

4. **数据结构与算法选择**：
   - 使用并查集（Union-Find）实现 Kruskal 算法
   - 并查集支持路径压缩
   - 对边按权值排序：时间复杂度 $O(M \log M)$

5. **时空复杂度分析**：
   - 时间复杂度：$O(M \log M)$ （排序） + $O(M \alpha(N))$ （并查集操作）
   - 空间复杂度：$O(N + M)$

#### 省流版

使用 Kruskal 算法求解最小生成树：将 M 条边按权值升序排序，依次选择不构成环的边加入生成树，若最终选够 N-1 条边则输出总权值，否则输出 `orz`。

#### 代码实现

```cpp
#include <stdlib.h>
#include <string.h>
#include <stack>

#include <vector>

int bingchaji[5010];
vector<pair<pair<int, int>, int>> bian; //起点 终点 长度

void add_bing(int a, int b){
    int s = bingchaji[b];

    while(s != bingchaji[s]){
        s = bingchaji[s];
    }

    bingchaji[s] = a;

    return;
}

int is_bing(int a, int b){
    int s1 = bingchaji[a];
    int s2 = bingchaji[b];

    while (s1 != bingchaji[s1]){
        s1 = bingchaji[s1];
    }
    while(s2 != bingchaji[s2]){
        s2 = bingchaji[s2];
    }

    bingchaji[a] = s1;
    bingchaji[b] = s2;

    if(s1 == s2){
        return 1;
    }else{
        return 0;
    }
}

int main(){
    int n, m;
    int a, b ,c;
    int chang = 0;

        scanf("%d%d%d", &a, &b, &c);
        bian.push_back({{a, b}, c});

    for(int i = 1; i <= n; i++){
        bingchaji[i] = i;
    }

        return a.second < b.second;
    });


    int flag = 0;
    for(auto it = bian.begin(); it != bian.end() && flag < n; it++){
        a = (*it).first.first;
        b = (*it).first.second;
        c = (*it).second;

            flag++;
            chang += c;
            add_bing(a, b);
        }
    }

    if(flag == n - 1){
        printf("%d\n", chang);
    }else{
        printf("orz\n");
    }
}
```

### 2.7 P4047 [JSOI2010] 部落划分

**题目链接**：https://www.luogu.com.cn/problem/P4047

**知识点**：并查集、最小生成树、Kruskal

**题目简述**：

> 有 n 个野人居住点，给每个点分配一个部落标签，要求恰好划分为 k 个部落。定义两个部落的距离为两部落中距离最近的两点间距离。求一种划分方式，使得最近的两个部落距离尽可能大，输出这个最大距离。
>
> 数据范围：$2 \le k \le n \le 10^3$。

#### 详细分析

1. **读题**：n 个平面点，需要划分为恰好 k 个部落。目标是最小化"最近两个部落的距离"中的最大值——即最大化最近部落间距离的下界。

2. **性质观察**：本题等价于求最小生成树（MST）。将所有 n 个点看作图的顶点，任意两点间边的权值为欧氏距离。当我们用 Kruskal 算法构造 MST 时，依次加入最短的边并合并连通块，直到只剩 k 个连通块。此时最后加入的那条边的权值即为答案。

3. **程序设计**：
   - 预处理所有点对距离，共 n(n-1)/2 条边
   - 使用并查集维护部落划分
   - 依次合并距离最近的两个部落
   - 合并 n-k 次后，答案为当前最小部落间距离

4. **数据结构与算法选择**：
   - 并查集：高效合并与查询部落归属
   - 边表：存储所有点对距离
   - Kruskal 思想：每次找最小边合并，直到剩 k 个集合

5. **时空复杂度分析**：
   - 时间：$O(n^2)$ 建图 + $O(n^2)$ 合并过程 = $O(n^2)$
   - 空间：$O(n^2)$ 距离矩阵

#### 省流版

将 n 个点用并查集不断合并成 k 个部落，每次合并距离最近的两个部落。合并 n-k 次后，当前最小的部落间距离即为答案。本质是 Kruskal 构造最小生成树到只剩 k 条边。

#### 代码实现

![AC截图](./P4047/P4047AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>
#include <vector>
#include <stack>
#include <queue>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int bingchaji[1010];
double dist[1010][1010];
int px[1010];
int py[1010];

void init(int n){
    for(int i = 0; i < n; i++){
        bingchaji[i] = i;
    }
}

int find(int a){
    int s = bingchaji[a];
    while(s != bingchaji[s]){
        s = bingchaji[s];
    }
    bingchaji[a] = s;
    return s;
}

void memgre(int a, int b){
    bingchaji[b] = find(a);
}

void find_min(int n, int* a, int* b){
    double mind = 10e6;
    for(int i = 0; i < n; i++){
        if(find(i) != i) continue;
        for(int j = 0; j < n; j++){
            if(dist[i][j] == 0) continue;
            if(dist[i][j] < mind){
                mind = dist[i][j];
                *a = i;
                *b = j;
            }
        }
    }
    return;
}

double find_min_dist(int n){
    double mind = 10e6;
    for(int i = 0; i < n; i++){
        if(find(i) != i) continue;
        for(int j = 0; j < n; j++){
            if(dist[i][j] == 0) continue;
            if(dist[i][j] < mind){
                mind = dist[i][j];
            }
        }
    }
    return mind;
}

void memgre_buluo(int n){
    int a, b;
    find_min(n, &a, &b);
    memgre(a, b);
    for(int i = 0; i < n; i++){
        if(dist[a][i] > dist[b][i]){
            dist[a][i] = dist[b][i];
            dist[i][a] = dist[a][i];
        }
    }
}

int main(){
    int n, k;
    scanf("%d%d", &n, &k);
    for(int i = 0; i < n; i++){
        scanf("%d%d", &px[i], &py[i]);
    }
    for(int i = 0; i < n; i++){
        for(int j = 0; j < n; j++){
            dist[i][j] = hypot(px[i] - px[j], py[i] - py[j]);
        }
    }

    init(n);
    for(int i = 0; i < n - k; i++){
        memgre_buluo(n);
    }

    printf("%.2lf\n", find_min_dist(n));
    return 0;
}
```

### 2.8 P4053 [JSOI2007] 建筑抢修

**题目链接**：https://www.luogu.com.cn/problem/P4053

**知识点**：贪心、优先队列（带反悔贪心）

**题目简述**：

> 有 n 个建筑需要修理，每个建筑 i 有两个属性：修理时间 T1 和报废时间 T2。如果在 T2 时刻之前没有完成修理，建筑就会报废（刚好在 T2 时刻完成不会报废）。求最多能修理好的建筑数量。
>
> 数据范围：$1 \le n \le 150000$。

#### 详细分析

1. **读题**：n 个建筑，每个有修理时间 T1 和报废时间 T2。同一时刻只能修理一个建筑，求能修理的最大数量。

2. **性质观察**：
   - 报废时间越早的建筑越紧迫，应该优先处理 —— 按 T2 升序排序
   - 当处理到某个建筑发现时间不够时，可以考虑用较短的修理时间替换已选中的较长修理时间
   - 用最大堆维护已选中建筑的修理时间，可以快速找到并替换最长的一项

3. **程序设计**：
   - 按报废时间 T2 升序排序所有建筑
   - 维护当前已用时间 `time` 和最大堆 `built`（存储已选建筑的 T1）
   - 遍历每个建筑：
     - 将当前建筑的 T1 加入堆，`time += T1`
     - 若 `time > T2`，说明无法按时完成，将堆顶（最大 T1）弹出，`time -= 弹出值`
   - 最终堆的大小即为答案

4. **数据结构与算法选择**：
   - `priority_queue` 实现最大堆，维护已选建筑的修理时间
   - 时间复杂度 $O(n \log n)$，空间复杂度 $O(n)$

5. **时空复杂度分析**：
   - 时间：排序 $O(n \log n)$ + 遍历 $O(n \log n)$ = $O(n \log n)$
   - 空间：堆中最多存储 n 个元素，$O(n)$

#### 省流版

按报废时间排序，依次处理每个建筑，用最大堆维护已选建筑的修理时间。当时间超出当前建筑的报废时间时，弹出堆中最大的修理时间进行替换（相当于反悔），最终堆的大小即为最多能修理的建筑数。

#### 代码实现

![AC截图](./P4053/P4053AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <queue>
#include <vector>
#include <algorithm>

using namespace std;

auto cmp = [](auto &a, auto &b) {
    if (a.second == b.second) {
        return a.first > b.first;
    } else {
        return a.second > b.second;
    }
};
priority_queue<pair<long long int, long long int>, vector<pair<long long int, long long int>>, decltype(cmp)> building(cmp);

auto cmp2 = [](auto &a, auto &b) {
    return a.first < b.first;
};
priority_queue<pair<long long int, long long int>, vector<pair<long long int, long long int>>, decltype(cmp2)> built(cmp2);

int main() {
    long long int n;
    long long int s = 0;
    long long int t1, t2;
    long long int time = 0;

    scanf("%lld", &n);
    for (long long int i = 0; i < n; i++) {
        scanf("%lld%lld", &t1, &t2);
        building.push({t1, t2});
    }

    while (!building.empty()) {
        t1 = building.top().first;
        t2 = building.top().second;
        building.pop();

        if (time + t1 <= t2) {
            s++;
            time += t1;
            built.push({t1, t2});
        } else {
            if (t1 < built.top().first) {
                time -= built.top().first;
                time += t1;
                building.push(built.top());
                built.pop();
                built.push({t1, t2});
            }
        }
    }

    printf("%lld\n", s);
}
```

### 2.9 P5019 [NOIP 2018 提高组] 铺设道路

**题目链接**：https://www.luogu.com.cn/problem/P5019

**知识点**：贪心、差分思想

**题目简述**：

> 一条道路由 $n$ 块连续区域组成，第 $i$ 块下陷深度为 $d_i$。每天可选一段连续区间 $[L,R]$，将区间内每块区域的下陷深度各减 $1$（要求操作时区间内每块深度均 $>0$）。求把所有区域填平所需的最少天数。
>
> 数据范围：$1\le n\le 10^5$，$0\le d_i\le 10^4$。

#### 详细分析

**1. 读题**

每天能把一段连续区间整体「下降」$1$。要把整个高度数组削平到 $0$，求最少操作天数。

**2. 性质观察**

**关键贪心结论**：从左到右考虑，答案 = $d_1 + \sum_{i=2}^{n}\max(0,\,d_i-d_{i-1})$。

直观理解：相邻两块比较，

- 若 $d_i > d_{i-1}$，高出的部分 $d_i-d_{i-1}$ 必须用新的操作来填，无法蹭到左边的区间；累加这部分增量；
- 若 $d_i \le d_{i-1}$，当前这一块可以「搭便车」——填左边时顺带把它也填了，不需要新增天数。

这正是「正差分之和」，等价于把高度折线中所有**上升沿**的高度累加起来。

**3. 数据结构与算法选择**

无需存储整个数组，只需在线读入：维护前一块高度 `hight`，逐块累加上升量。

**4. 程序设计**

1. `day=0, hight=0`；
2. 逐块读入 `road`：若 `road > hight`，则 `day += road - hight`；
3. 更新 `hight = road`；
4. 输出 `day`。

**5. 时空复杂度分析**

单次线性扫描，时间复杂度 $O(n)$，空间 $O(1)$。$n\le 10^5$ 可以通过。

#### 省流版

贪心 / 差分。答案等于高度折线所有上升沿之和：从左到右，只要当前块比前一块高，就把高出的部分累加到天数；不高于则可蹭前面的操作。时间复杂度 $O(n)$，空间 $O(1)$。

#### 代码实现

![AC截图](./P5019/P5019AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <queue>
#include <stack>
#include <string>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

	int n;
	int day = 0;
	int road;
	int hight = 0;

	scanf("%d", &n);
	for(int i = 0; i < n; i++){
		scanf("%d", &road);
		if(road > hight){
			day += road - hight;
		}
		hight = road;
	}

	printf("%d\n", day);
}
```

### 2.10 P1967 [NOIP 2013 提高组] 货车运输

**题目链接**：https://www.luogu.com.cn/problem/P1967

**知识点**：图论、最大生成树、LCA、树上路径最小值

**题目简述**：

> A 国有 $n$ 座城市、$m$ 条双向道路，每条道路有载重限制 $z$。现有 $q$ 辆货车，每辆从城市 $x$ 前往城市 $y$，求在不超过限重的情况下最多能运多重的货物。若无法到达，输出 $-1$。
>
> 数据范围：$n < 10^4$，$m < 5\times 10^4$，$q < 3\times 10^4$。

#### 详细分析

**1. 读题**

货车从 $x$ 到 $y$，路径上每条路都有各自的限重。为了不超载，货车载重不能超过路径上最小限重。题目要求的是所有路径中，这个最小限重的最大值，也就是“最大瓶颈路径”问题。

**2. 性质观察**

最大瓶颈路径有一个经典结论：将图的所有边按权值从大到小排序，依次加入并查集，第一次使 $x$ 和 $y$ 连通时，当前边的权值就是 $x$ 到 $y$ 的最大瓶颈值。

这等价于：构造一张**最大生成树**，则 $x$ 到 $y$ 在树上的唯一路径上的最小边权，就是答案。

**3. 数据结构与算法选择**

- 使用 **Kruskal** 算法构建最大生成树。
- 在树上使用 **倍增 LCA** 维护从节点到其 $2^k$ 级祖先路径上的最小边权。
- 每次查询时，先让两个节点跳到同一深度，再一起向上跳，过程中维护最小边权。

**4. 程序设计**

- 读入边，按权值降序排序。
- Kruskal 建最大生成树，同时用并查集维护连通性。
- 对每个连通块的根节点，DFS 预处理每个节点的深度、`parent[0]`、`minw[0]`。
- 倍增预处理 `parent[k][i]` 和 `minw[k][i]`。
- 处理每个询问：若两点不在同一连通块输出 $-1$；否则通过 LCA 查询路径最小边权。

**5. 时空复杂度分析**

时间复杂度：Kruskal 排序 $O(m \log m)$，倍增预处理 $O(n \log n)$，每次查询 $O(\log n)$，总复杂度 $O((m+n+q) \log n)$。
空间复杂度：$O(n \log n + m)$。

#### 省流版

最大生成树 + 倍增 LCA 维护路径最小边权，树上两点路径最小值即为最大载重。

#### 代码实现

![AC截图](./P1967/P1967AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

struct Edge{
	int u, v, w;
}edge[50010];

struct Node{
	int to;
	int w;
};

bool cmp(Edge a, Edge b){
	return a.w > b.w;
}

int n, m, q;
int fa[10010];
int depth[10010];
int parent[20][10010];
int minw[20][10010];
vector<Node> tree[10010];

int find(int x){
	if(fa[x] == x) return x;
	return fa[x] = find(fa[x]);
}

void dfs(int u, int p){
	parent[0][u] = p;
	for(int i = 0; i < (int)tree[u].size(); i++){
		int v = tree[u][i].to;
		int w = tree[u][i].w;
		if(v == p) continue;
		depth[v] = depth[u] + 1;
		minw[0][v] = w;
		dfs(v, u);
	}
}

int lca(int u, int v){
	int ans = 1000000000;
	if(depth[u] < depth[v]){
		int t = u; u = v; v = t;
	}
	for(int k = 15; k >= 0; k--){
		if(depth[parent[k][u]] >= depth[v]){
			if(minw[k][u] < ans) ans = minw[k][u];
			u = parent[k][u];
		}
	}
	if(u == v) return ans;
	for(int k = 15; k >= 0; k--){
		if(parent[k][u] != parent[k][v]){
			if(minw[k][u] < ans) ans = minw[k][u];
			if(minw[k][v] < ans) ans = minw[k][v];
			u = parent[k][u];
			v = parent[k][v];
		}
	}
	if(minw[0][u] < ans) ans = minw[0][u];
	if(minw[0][v] < ans) ans = minw[0][v];
	return ans;
}

int main(){
	scanf("%d%d", &n, &m);
	for(int i = 0; i < m; i++){
		scanf("%d%d%d", &edge[i].u, &edge[i].v, &edge[i].w);
	}

	sort(edge, edge + m, cmp);
	for(int i = 1; i <= n; i++) fa[i] = i;
	for(int i = 0; i < m; i++){
		int fu = find(edge[i].u);
		int fv = find(edge[i].v);
		if(fu != fv){
			fa[fu] = fv;
			tree[edge[i].u].push_back((Node){edge[i].v, edge[i].w});
			tree[edge[i].v].push_back((Node){edge[i].u, edge[i].w});
		}
	}

	memset(minw, 0x3f, sizeof(minw));
	for(int i = 1; i <= n; i++){
		if(fa[i] == i){
			depth[i] = 1;
			minw[0][i] = 1000000000;
			dfs(i, i);
		}
	}

	for(int k = 1; k <= 15; k++){
		for(int i = 1; i <= n; i++){
			parent[k][i] = parent[k-1][parent[k-1][i]];
			minw[k][i] = min(minw[k-1][i], minw[k-1][parent[k-1][i]]);
		}
	}

	scanf("%d", &q);
	for(int i = 0; i < q; i++){
		int u, v;
		scanf("%d%d", &u, &v);
		if(find(u) != find(v)){
			printf("-1\n");
		}else{
			printf("%d\n", lca(u, v));
		}
	}
}
```

### 2.11 P4779 【模板】单源最短路径（标准版）

**题目链接**：https://www.luogu.com.cn/problem/P4779

**知识点**：图论、最短路、Dijkstra、优先队列

**题目简述**：

> 给定一个 $n$ 个点、$m$ 条有向边的带非负权图，求从源点 $s = 1$ 出发到每个点的最短距离。
>
> 数据范围：$n \le 10^5$，$m \le 2\times 10^5$。

#### 详细分析

**1. 读题**

经典单源最短路模板题，图中有向、边权非负，适合使用 Dijkstra 算法。

**2. 性质观察**

Dijkstra 算法基于贪心思想：每次从未确定最短路的点中选择距离源点最近的点，用它更新邻居的距离。由于边权非负，一旦一个点被确定，其最短路不会再被更新。

**3. 数据结构与算法选择**

使用 **优先队列（小根堆）优化 Dijkstra**。朴素做法每次找最近点需要 $O(n)$，总复杂度 $O(n^2)$；堆优化后每次取点和更新都是 $O(\log n)$，总复杂度 $O((n+m) \log n)$。

**4. 程序设计**

- 使用邻接表存图。
- `dis[i]` 表示源点到 $i$ 的当前最短距离，初始为 `INF`，`dis[s] = 0`。
- `vis[i]` 标记是否已经确定最短路。
- 优先队列中存放 `(距离, 节点)`，每次取距离最小的节点。
- 若该节点已被访问则跳过；否则用它更新所有邻居的距离。
- 最后输出 `dis[1..n]`。

**5. 时空复杂度分析**

时间复杂度：$O((n + m) \log n)$。
空间复杂度：$O(n + m)$。

#### 省流版

堆优化 Dijkstra：小根堆维护当前最短距离，每次取最近点松弛邻居，直到所有点确定。

#### 代码实现

### 2.13 P8802 [蓝桥杯 2022 国 B] 出差

**题目链接**：https://www.luogu.com.cn/problem/P8802

**知识点**：图论、最短路、Dijkstra

**题目简述**：

> A 国有 $N$ 个城市、$M$ 条双向道路。小明从城市 $1$ 出发前往城市 $N$，每条道路有通过时间。到达一个城市后需要隔离 $C_i$ 时间才能离开（城市 $1$ 可直接离开，城市 $N$ 到达后无需再隔离）。求最短时间。
>
> 数据范围：$N \le 1000$，$M \le 10000$，$C_i \le 200$，道路时间 $c \le 1000$。

#### 详细分析

**1. 读题**

路线是双向的，到达中间城市 $i$ 后需付出 $C_i$ 的隔离时间才能继续出发；起点城市 $1$ 已经人在其中，可直接离开；终点城市 $N$ 到达即结束，不再隔离。

**2. 性质观察**

可以把“离开城市 $u$ 前往 $v$”的代价拆分为：道路时间 $c(u,v)$ + 在城市 $u$ 的隔离时间 $C_u$（$u=1$ 时隔离时间为 $0$）。这样原图变成边权重新定义的带权图，问题转化为求 $1$ 到 $N$ 的最短路。

**3. 数据结构与算法选择**

边权均为正，使用 **堆优化 Dijkstra**。$N$ 只有 $1000$，完全够用。

**4. 程序设计**

- 读入 $N$、$M$ 与各城市隔离时间 $C[i]$。
- 建无向图邻接表。
- Dijkstra 松弛边 $u \to v$ 时，实际代价为 `w + (u == 1 ? 0 : C[u])`。
- 输出 `dis[N]`。

**5. 时空复杂度分析**

时间复杂度：$O((N+M) \log N)$。
空间复杂度：$O(N + M)$。

#### 省流版

把每个城市的隔离时间加在 outgoing 的边权上（起点除外），跑一遍 Dijkstra 即可。

### 2.14 P1948 [USACO08JAN] Telephone Lines S

**题目链接**：https://www.luogu.com.cn/problem/P1948

**知识点**：图论、最短路、二分答案、0-1 BFS

**题目简述**：

> 有 $n$ 根电话线杆、$p$ 条可选双向电话线，第 $i$ 条长度 $l_i$。电信公司免费连接其中 $k$ 条，其余由自己付费，费用等于剩余电话线中最长的一根。求把 $1$ 号杆连到 $n$ 号杆的最小支出；若无法连通输出 $-1$。
>
> 数据范围：$n \le 1000$，$p \le 10000$，$l_i \le 10^6$。

#### 详细分析

**1. 读题**

只需要保证 $1$ 到 $n$ 之间存在一条路径，路径上最多 $k$ 条边可以免费，其余边需要自费，费用为这些自费边长度的最大值。要使这个最大值最小。

**2. 性质观察**

对某个费用上限 $x$，若存在一条 $1 \to n$ 的路径，其中长度大于 $x$ 的边不超过 $k$ 条，则答案 $\le x$。这个判断具有单调性：$x$ 越大越容易满足，因此可以二分答案。

**3. 数据结构与算法选择**

- **二分答案**：在 $[0, \max(l_i)]$ 上二分最小可行的 $x$。
- **0-1 BFS**：对固定的 $x$，把每条边变成 $0$（$l_i \le x$）或 $1$（$l_i > x$），求 $1$ 到 $n$ 的最少“贵边”数。若该数 $\le k$，则 $x$ 可行。

**4. 程序设计**

- 读入图，记录最大边长。
- 二分 $x$，调用 `check(x)`：
  - 初始化 `dis[1] = 0`，其余为 `INF`，双端队列放入 $1$。
  - 0-1 BFS：$0$ 代价边从队首入队，$1$ 代价边从队尾入队。
  - 返回 `dis[n] <= k`。
- 找到最小可行 $x$ 输出；否则输出 $-1$。

**5. 时空复杂度分析**

时间复杂度：二分 $O(\log \max L)$ 次，每次 0-1 BFS 为 $O(n + p)$，总复杂度 $O((n + p) \log \max L)$。
空间复杂度：$O(n + p)$。

#### 省流版

二分答案 $x$，把边按是否大于 $x$ 标为 $0/1$，跑 0-1 BFS 看 $1$ 到 $n$ 是否需要超过 $k$ 条“贵边”。最小可行的 $x$ 即为答案。

#### 代码实现

![AC截图](./P1948/P1948AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

const int INF = 0x3f3f3f3f;

int n, p, k;
vector<pair<int, int>> g[1010];
int dis[1010];
deque<int> dq;

// 检查是否存在 1 到 n 的路径，其中长度大于 x 的边不超过 k 条
bool check(int x){
	memset(dis, 0x3f, sizeof(dis));
	dis[1] = 0;
	dq.clear();
	dq.push_back(1);
	while(!dq.empty()){
		int u = dq.front();
		dq.pop_front();
		for(int i = 0; i < (int)g[u].size(); i++){
			int v = g[u][i].first;
			int w = g[u][i].second;
			int cost = (w > x) ? 1 : 0;
			if(dis[u] + cost < dis[v]){
				dis[v] = dis[u] + cost;
				if(cost == 0){
					dq.push_front(v);
				}else{
					dq.push_back(v);
				}
			}
		}
	}
	return dis[n] <= k;
}

int main(){
	scanf("%d%d%d", &n, &p, &k);
	int maxL = 0;
	for(int i = 0; i < p; i++){
		int a, b, l;
		scanf("%d%d%d", &a, &b, &l);
		g[a].push_back(make_pair(b, l));
		g[b].push_back(make_pair(a, l));
		if(l > maxL) maxL = l;
	}

	int left = 0, right = maxL, ans = -1;
	while(left <= right){
		int mid = (left + right) / 2;
		if(check(mid)){
			ans = mid;
			right = mid - 1;
		}else{
			left = mid + 1;
		}
	}

	printf("%d\n", ans);
}
```

**题目简述**：

> $n$ 个城市、$m$ 条双向航线，每条航线有价格。从 $s$ 到 $t$，最多可以免费乘坐 $k$ 条航线，求最小花费。
>
> 数据范围：$n \le 10^4$，$m \le 5\times 10^4$，$k \le 10$，$c \le 10^3$。

#### 详细分析

**1. 读题**

每条航线最多使用一次免费机会，也可以付费。需要找到从 $s$ 到 $t$ 的最小总花费。

**2. 性质观察**

免费次数 $k$ 很小（$\le 10$），可以把“已经使用了多少次免费机会”作为额外一维状态，构建分层图：第 $j$ 层表示已经使用了 $j$ 次免费机会。

**3. 数据结构与算法选择**

- **分层图 + Dijkstra**：状态为 `(节点, 已用免费次数)`，总状态数不超过 $n \times (k+1)$。
- 对每条边有两种转移：
  - 付费走：停留在同一层，花费 $+c$；
  - 免费走：进入下一层，花费 $+0$（需满足已用次数 $< k$）。

**4. 程序设计**

- 读入图。
- 初始化 `dis[s][0] = 0`，优先队列按花费小根堆。
- Dijkstra 过程中同时处理“付费”和“免费”两种转移。
- 答案为 $\min(dis[t][0..k])$。

**5. 时空复杂度分析**

时间复杂度：状态数 $O(nk)$，每个状态扩展 $O(\deg)$，总复杂度 $O(mk \log(nk))$。
空间复杂度：$O(nk + m)$。

#### 省流版

把“已用免费次数”扩展成一维，跑分层图 Dijkstra。每条边可付费同层走或免费进入下一层。

#### 代码实现

![AC截图](./P4568/P4568AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

const long long INF = 0x3f3f3f3f3f3f3f3fLL;

int n, m, k;
int s, t;
vector<pair<int, int>> g[10010];
long long dis[10010][12];
int vis[10010][12];

struct State{
	int u;
	int used;
	long long d;
	bool operator<(const State& other) const {
		return d > other.d;
	}
};

void dijkstra(){
	priority_queue<State> pq;
	memset(dis, 0x3f, sizeof(dis));
	dis[s][0] = 0;
	pq.push((State){s, 0, 0});
	while(!pq.empty()){
		State cur = pq.top();
		pq.pop();
		int u = cur.u;
		int used = cur.used;
		if(vis[u][used]) continue;
		vis[u][used] = 1;
		for(int i = 0; i < (int)g[u].size(); i++){
			int v = g[u][i].first;
			int w = g[u][i].second;
			// 付费走，层数不变
			if(dis[u][used] + w < dis[v][used]){
				dis[v][used] = dis[u][used] + w;
				pq.push((State){v, used, dis[v][used]});
			}
			// 免费走，进入下一层
			if(used < k && dis[u][used] < dis[v][used + 1]){
				dis[v][used + 1] = dis[u][used];
				pq.push((State){v, used + 1, dis[v][used + 1]});
			}
		}
	}
}

int main(){
	scanf("%d%d%d", &n, &m, &k);
	scanf("%d%d", &s, &t);
	for(int i = 0; i < m; i++){
		int a, b, c;
		scanf("%d%d%d", &a, &b, &c);
		g[a].push_back(make_pair(b, c));
		g[b].push_back(make_pair(a, c));
	}

	dijkstra();

	long long ans = INF;
	for(int i = 0; i <= k; i++){
		if(dis[t][i] < ans) ans = dis[t][i];
	}

	printf("%lld\n", ans);
}
```

### 2.16 P2168 [NOI2015] 荷马史诗

**题目链接**：https://www.luogu.com.cn/problem/P2168

**知识点**：贪心、哈夫曼树、K 叉哈夫曼、优先队列

**题目简述**：

> 有 $n$ 种单词，第 $i$ 种单词出现 $w_i$ 次。要用 $k$ 进制字符串 $s_i$ 替换这些单词，且任意 $s_i$ 不是 $s_j$ 的前缀。求重新编码后总长度最小值；并在所有最优方案中，求最长字符串长度的最小值。
>
> 数据范围：$1\le n\le 10^5$，$2\le k\le 9$，$0< w_i\le 10^{11}$。

#### 详细分析

**1. 读题**

前缀-free 编码等价于构建一棵 $k$ 叉编码树：叶子对应单词，根到叶子的路径字符组成该单词编码。总长度等于 $\sum w_i\times depth_i$，最长字符串长度等于最大叶子深度。

**2. 性质观察**

最小化 $\sum w_i\times depth_i$ 正是 $k$ 叉哈夫曼树的目标。为使最大深度也最小，合并时若权值相同，应优先合并高度较小的节点，使树更平衡。

**3. 数据结构与算法选择**

- 使用**小根堆**维护当前节点集合，每次取出 $k$ 个权值最小的节点合并；
- 权值相同时以节点高度为第二关键字，优先取高度较小者；
- $k$ 叉哈夫曼要求总叶子数 $L$ 满足 $(L-1)\bmod (k-1)=0$，否则需补权值为 $0$ 的虚拟叶子。

**4. 程序设计**

1. 读入 $n$、$k$ 与权值，全部作为叶子节点入堆（高度为 $0$）；
2. $n=1$ 时直接输出 `0` 与 `0`；
3. 计算需要补齐的虚拟节点数 `pad = (k-1-(n-1)%(k-1))%(k-1)`，并入堆；
4. 每次合并 $k$ 个节点：新节点权值为子节点权和，高度为子节点最大高度 $+1$；累计权和到答案；
5. 最后输出累计权和（最小编码总长度）与根节点高度（最长字符串最短长度）。

**5. 时空复杂度分析**

建堆 $O(n)$，每次合并弹出/压入 $k$ 个节点，共约 $\frac{n}{k-1}$ 次合并，时间复杂度 $O(n\log n)$；空间复杂度 $O(n)$。注意权值和可能达到 $10^{16}$ 量级，需用 `long long`。

#### 省流版

$k$ 叉哈夫曼树。小根堆每次合并 $k$ 个最小权值节点，权值相同优先合并高度小的；合并过程中累加内部节点权值得到最小编码总长度，根高度即最长字符串的最短长度。注意补齐虚拟节点与 `long long`。

#### 代码实现

![AC截图](./P2168/P2168AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

struct Node{
	long long w;
	int h;
};

struct CMP{
	bool operator()(const Node& a, const Node& b) const {
		if(a.w != b.w) return a.w > b.w; // 小根堆，先合并权值小的
		return a.h > b.h;               // 权值相同时先合并高度小的，保证树更平衡
	}
};

priority_queue<Node, vector<Node>, CMP> pq;

int main(){
	int n, k;
	scanf("%d%d", &n, &k);
	for(int i = 0; i < n; i++){
		long long w;
		scanf("%lld", &w);
		pq.push((Node){w, 0});
	}

	if(n == 1){
		printf("0\n0\n");
		return 0;
	}

	// 补齐虚拟节点，使 (总叶子数 - 1) 能被 (k - 1) 整除
	int pad = (k - 1 - (n - 1) % (k - 1)) % (k - 1);
	for(int i = 0; i < pad; i++){
		pq.push((Node){0, 0});
	}

	long long total = 0;
	while((int)pq.size() > 1){
		long long sum = 0;
		int maxH = 0;
		for(int i = 0; i < k; i++){
			Node cur = pq.top();
			pq.pop();
			sum += cur.w;
			if(cur.h > maxH) maxH = cur.h;
		}
		total += sum;
		pq.push((Node){sum, maxH + 1});
	}

	Node root = pq.top();
	printf("%lld\n%d\n", total, root.h);
}
```

### 2.17 P1080 [NOIP 2012 提高组] 国王游戏

**题目链接**：https://www.luogu.com.cn/problem/P1080

**知识点**：贪心、排序、高精度

**题目简述**：

> 国王站在队伍最前面，左手 $a_0$、右手 $b_0$。随后有 $n$ 位大臣，每人左手 $a_i$、右手 $b_i$。大臣的奖赏为排在他前面所有人左手数的乘积除以他自己右手的数向下取整。重新安排大臣顺序，使获得奖赏最多的大臣的奖赏尽可能少。
>
> 数据范围：$1\le n\le 1000$，$0\lt a,b\lt 10000$。

#### 详细分析

**1. 读题**

国王位置固定，只需求大臣的排列顺序。设某排列中第 $i$ 个大臣前面所有人的左手乘积为 $P_i$，则该大臣奖赏为 $\left\lfloor \frac{P_i}{b_i}\right\rfloor$。

**2. 性质观察**

考虑相邻两位大臣 $i$、$j$（$i$ 在 $j$ 前面），前面乘积为 $P$。此时这一段的答案贡献为 $\max\left(\left\lfloor\frac{P}{b_i}\right\rfloor,\left\lfloor\frac{P\cdot a_i}{b_j}\right\rfloor\right)$。若交换为 $j$ 在前、$i$ 在后，则贡献为 $\max\left(\left\lfloor\frac{P}{b_j}\right\rfloor,\left\lfloor\frac{P\cdot a_j}{b_i}\right\rfloor\right)$。通过比较可知，当 $a_i\cdot b_i\le a_j\cdot b_j$ 时，$i$ 排在 $j$ 前面不更劣。因此最优顺序按 $a_i\cdot b_i$ 升序排列。

**3. 数据结构与算法选择**

- 贪心排序：按 `a_i * b_i` 升序排列大臣；
- 高精度计算：乘积最大可达 $10000^{1000}$，远超 64 位整数，需手写大整数（乘小整数、除小整数、比较大小）。

**4. 程序设计**

1. 读入国王与 $n$ 位大臣的信息；
2. 按 `a_i * b_i` 升序排序；
3. 用大整数维护前面所有人的左手乘积 $P$（初始为 $a_0$）；
4. 遍历大臣：先计算 $\left\lfloor\frac{P}{b_i}\right\rfloor$ 并更新最大奖赏，再令 $P\leftarrow P\times a_i$；
5. 输出最大奖赏。

**5. 时空复杂度分析**

排序 $O(n\log n)$；高精度乘除的位数约为 $O(\log_{10}(a_0\cdot \prod a_i))\le 4000$，每次 $O(D)$。总时间复杂度 $O(n\log n+nD)$；空间复杂度 $O(D)$。

#### 省流版

按 $a_i\cdot b_i$ 升序排大臣，然后模拟乘积并用高精度计算每个大臣的奖赏，取最大值。

#### 代码实现

![AC截图](./P1080/P1080AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

// 大整数：低位在前，每位 0~9
struct BigNum{
	vector<int> d;
};

void mul(BigNum& num, int x){
	int carry = 0;
	for(int i = 0; i < (int)num.d.size(); i++){
		int prod = num.d[i] * x + carry;
		num.d[i] = prod % 10;
		carry = prod / 10;
	}
	while(carry){
		num.d.push_back(carry % 10);
		carry /= 10;
	}
}

BigNum divSmall(const BigNum& num, int x){
	BigNum res;
	res.d.resize(num.d.size());
	long long rem = 0;
	for(int i = (int)num.d.size() - 1; i >= 0; i--){
		rem = rem * 10 + num.d[i];
		res.d[i] = (int)(rem / x);
		rem %= x;
	}
	while(res.d.size() > 1 && res.d.back() == 0){
		res.d.pop_back();
	}
	return res;
}

bool greaterThan(const BigNum& a, const BigNum& b){
	if(a.d.size() != b.d.size()) return a.d.size() > b.d.size();
	for(int i = (int)a.d.size() - 1; i >= 0; i--){
		if(a.d[i] != b.d[i]) return a.d[i] > b.d[i];
	}
	return false;
}

void print(const BigNum& num){
	for(int i = (int)num.d.size() - 1; i >= 0; i--){
		printf("%d", num.d[i]);
	}
	printf("\n");
}

struct Minister{
	int a, b;
	long long prod;
};

bool cmp(const Minister& x, const Minister& y){
	return x.prod < y.prod;
}

Minister ministers[1010];

int main(){
	int n;
	scanf("%d", &n);
	int a0, b0;
	scanf("%d%d", &a0, &b0);
	for(int i = 0; i < n; i++){
		scanf("%d%d", &ministers[i].a, &ministers[i].b);
		ministers[i].prod = 1LL * ministers[i].a * ministers[i].b;
	}

	sort(ministers, ministers + n, cmp);

	BigNum P;
	P.d.clear();
	int t = a0;
	while(t){
		P.d.push_back(t % 10);
		t /= 10;
	}
	if(P.d.empty()) P.d.push_back(0);

	BigNum ans;
	ans.d.push_back(0);

	for(int i = 0; i < n; i++){
		BigNum reward = divSmall(P, ministers[i].b);
		if(greaterThan(reward, ans)){
			ans = reward;
		}
		mul(P, ministers[i].a);
	}

	print(ans);
}
```

### 2.18 P1485 火枪打怪

**题目链接**：https://www.luogu.com.cn/problem/P1485

**知识点**：二分答案、贪心、滑动窗口

**题目简述**：

> $n$ 只怪物排成一排，第 $i$ 只血量为 $m_i$。LXL 可以发射 $k$ 发子弹，每发威力为 $p$。射向第 $i$ 只怪物时，该怪物掉 $p$ 点血，左边第 $j$ 只怪物（$j\lt i$）受到 $\max(0,p-(i-j)^2)$ 的溅射伤害。求能消灭所有怪物的最小正整数 $p$。
>
> 数据范围：$1\le n,k\le 5\times 10^5$，$1\le m_i\le 10^{10}$。

#### 详细分析

**1. 读题**

子弹伤害分为直接命中 $p$ 和向左的二次函数衰减溅射。需要找到最小的威力 $p$，使得存在一种射击方案用不超过 $k$ 发子弹消灭全部怪物。

**2. 性质观察**

对固定的 $p$，判断可行性具有单调性：$p$ 越大越容易满足，因此可以二分答案。溅射只向左，所以从右向左贪心：每个怪物只需要右侧子弹的溅射加上自己在该位置补射的子弹即可被消灭，补射量取最小值。

**3. 数据结构与算法选择**

- 二分答案，范围 $[1,\max(m_i)+(n-1)^2+1]$，上界对应“一枪打在最右端即可全覆盖”；
- 使用滑动窗口维护溅射和：对固定的 $p$，溅射有效距离 $R=\max\{d\mid d^2\lt p\}$。第 $i$ 个怪物只受位置在 $[i+1,\min(n,i+R)]$ 的子弹影响。设窗口内子弹数为 $S_0$、带权和 $S_1=\sum x_j\cdot j$、平方和 $S_2=\sum x_j\cdot j^2$，则怪物 $i$ 收到的溅射为
  $$\sum x_j\cdot(p-(j-i)^2)=p\cdot S_0-S_2+2i\cdot S_1-i^2\cdot S_0,$$
  可在 $O(1)$ 时间内计算。

**4. 程序设计**

1. 二分 $p$；
2. `check(p)`：从右向左扫描，用三个滑动变量维护窗口 $[i+1,\min(n,i+R)]$；
3. 若当前怪物 $i$ 的溅射 $\le m_i$，则需补射 $x_i=\left\lfloor\frac{m_i-splash}{p}\right\rfloor+1$ 发；
4. 累计子弹数，超过 $k$ 则不可行；
5. 扫描完若累计 $\le k$，则 $p$ 可行。

**5. 时空复杂度分析**

二分 $O(\log(\max m_i+n^2))$ 次，每次 `check` 为 $O(n)$，总时间复杂度 $O(n\log(\max m_i+n^2))$；空间复杂度 $O(n)$。

#### 省流版

二分答案 $p$，从右向左贪心求最少子弹数；用滑动窗口和三个系数和 $O(1)$ 计算每个怪物受到的溅射伤害。

#### 代码实现

![AC截图](./P1485/P1485AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <math>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

const int MAXN = 500010;

long long m[MAXN];
long long x[MAXN];
long long n, k;

// 检查威力为 p 时，k 发子弹是否足够
bool check(long long p){
	if(p <= 0) return false;
	// 最大溅射距离：满足 d^2 < p 的最大 d
	long long R = (long long)sqrt((long double)(p - 1));
	while((R + 1) * (R + 1) < p) R++;
	while(R * R >= p) R--;

	memset(x, 0, sizeof(long long) * (n + 2));
	long long S0 = 0, S1 = 0, S2 = 0; // 窗口内 x_j, x_j*j, x_j*j*j
	long long total = 0;

	for(long long i = n; i >= 1; i--){
		// 当前窗口为 [i+1, min(n, i+R)]，已包含所有能溅射到 i 的右侧子弹
		long long splash = p * S0 - S2 + 2LL * i * S1 - i * i * S0;
		if(splash <= m[i]){
			long long need = m[i] - splash;
			x[i] = need / p + 1;
			total += x[i];
			if(total > k) return false;
		}
		// 把第 i 个怪物处的子弹加入窗口，供左侧怪物计算溅射
		S0 += x[i];
		S1 += x[i] * i;
		S2 += x[i] * i * i;
		// 窗口右边界收缩：对于下一个 i-1，窗口上界为 i-1+R，需去掉 i+R
		if(i + R <= n){
			long long j = i + R;
			S0 -= x[j];
			S1 -= x[j] * j;
			S2 -= x[j] * j * j;
		}
	}
	return total <= k;
}

int main(){
	scanf("%lld%lld", &n, &k);
	long long maxM = 0;
	for(long long i = 1; i <= n; i++){
		scanf("%lld", &m[i]);
		if(m[i] > maxM) maxM = m[i];
	}

	long long left = 1;
	long long right = maxM + (n - 1) * (n - 1) + 1;
	while(left < right){
		long long mid = left + (right - left) / 2;
		if(check(mid)){
			right = mid;
		}else{
			left = mid + 1;
		}
	}

	printf("%lld\n", left);
}
```

## 三、算法思想总结

### 3.1 本章核心算法思想

#### 贪心算法的基本思想

贪心算法（Greedy Algorithm）在每一步决策时都选择当前看起来最优的选项，希望通过局部最优的累积达到全局最优。贪心算法要正确应用，通常需要满足两个条件：
- **贪心选择性质**：全局最优可以通过一系列局部最优选择得到；
- **最优子结构**：问题的最优解包含子问题的最优解。

在本题单中，每一道题都体现了不同的贪心策略。

#### 各类贪心策略总结

**1. 哈夫曼贪心**

- **B2168 哈夫曼编码**：每次合并权值最小的两个节点，使高频词编码最短。贪心最优性可通过交换论证证明。

**2. 排序 + 双指针 / 区间调度**

- **P1094 纪念品分组**：排序后双指针配对，让贵的尽量与便宜的配对，减少单独成组。
- **P1803 线段覆盖**：按结束时间（或等价的开始时间替换策略）选择活动，使剩余时间最大化。

**3. 最小/最大生成树**

- **P1546 Agri-Net（Prim）**：每次选择距已选集合最近的点加入，逐步扩展生成树。
- **P3366 最小生成树（Kruskal）**：按边权从小到大选边，用并查集判环。
- **P4047 部落划分（Kruskal 扩展）**：合并到只剩 k 个集合，最后加入的边即为最大最近距离。
- **P2700 逐个击破（最大生成树思想）**：按边权从大到小保留边，两边都有占领城市时被迫破坏。

**4. 反悔贪心**

- **P4053 建筑抢修**：按截止时间排序，用最大堆维护已选任务。当时间超限时，弹出耗时最长的任务（反悔），用更短的任务替换。

**5. 差分贪心**

- **P5019 铺设道路**：把问题转化为高度折线的上升沿之和，每个上升沿对应一次新的操作。

**6. 最短路**

- **P4779 单源最短路径（标准版）**：堆优化 Dijkstra，处理非负权图的单源最短路。
- **P2984 Chocolate Giving S**：以固定点 1 为源点跑一次 Dijkstra，回答所有询问。
- **P8802 出差**：把城市隔离时间附加在 outgoing 边权上，再跑 Dijkstra。
- **P4568 飞行路线**：把“已用免费次数”作为额外维度，构建分层图后跑 Dijkstra。

**7. 二分答案**

- **P1948 Telephone Lines S**：二分答案 x，把边按是否大于 x 标为 0/1，跑 0-1 BFS 判断可行性。
- **P1485 火枪打怪**：二分子弹威力 p，从右向左贪心验证 k 发是否足够。

**8. 贪心排序 + 高精度**

- **P1080 国王游戏**：按 a_i·b_i 升序排列大臣，用大整数维护乘积与奖赏。

**9. K 叉哈夫曼树**

- **P2168 荷马史诗**：扩展哈夫曼树到 k 叉，合并时按权值、高度双关键字取最小，补齐虚拟节点使 (L−1) mod (k−1)=0。

### 3.3 常见解题模式与技巧

1. **哈夫曼问题**：看到「合并代价」、「编码长度 × 频次最小」等关键词，考虑哈夫曼树 + 小根堆。
2. **区间调度**：看到「最多不相交区间」、「最多活动数」等，考虑按结束时间排序贪心。
3. **生成树问题**：看到「连接所有点的最小代价」、「划分集合」等，考虑 Prim 或 Kruskal。
4. **反悔贪心**：当贪心过程中发现当前选择导致后续无法完成时，用堆维护已选元素，适时「反悔」替换。
5. **双指针**：排序后从两端向中间扫描，常用于配对、分组问题。
6. **差分/扫描**：看到「连续区间操作」、「填平高度」等，考虑相邻元素的差分关系。
7. **最短路**：看到「最小代价到达」、「多询问距离」等，考虑 Dijkstra（非负权）或 SPFA（有负权）。
8. **二分答案**：看到「最小化最大值」、「最大化最小值」、「判断某个值是否可行」等，考虑二分 + 验证。
9. **分层图**：看到「最多使用 k 次免费/特权」等，考虑把使用次数作为额外维度建图。
10. **高精度**：当计算结果可能远超 64 位整数范围时，手写大整数（如乘除小整数）。
11. **long long 的使用**：当权值累加可能很大时（如哈夫曼权值、生成树边权），使用 `long long`。
