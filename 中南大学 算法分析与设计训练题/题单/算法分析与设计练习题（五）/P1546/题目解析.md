# [USACO3.1] 最短网络 Agri-Net

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P1546

知识点：最小生成树、Prim算法

## 题目简述

> 已知N个农场的连接费用矩阵（对称），求连接所有农场所需的最小光纤长度。
>
> 数据范围：3 ≤ N ≤ 100，每两个农场间距离 ≤ 10^5
>
> 时间限制：1S，空间限制：64MB

## 题目分析

### 详细版

1. 读题：给定一个N×N的完全带权图矩阵，求解使所有节点连通的最小生成树权值。

2. 性质观察：
   - 费用矩阵对称（无向图）
   - 对角线为0（自己到自己不需要连接）
   - 求最小生成树的总权值

3. 程序设计：
   - 初始化smalltree数组为从节点0到各个节点的距离
   - 循环N-1次，每次找到距离最小的节点加入生成树
   - 加入节点后，更新其他节点到生成树的最小距离

4. 算法选择：Prim算法（从节点0出发逐步构建最小生成树）

5. 时空复杂度：
   - 时间复杂度：O(N²)
   - 空间复杂度：O(N²) 存储矩阵 + O(N) 辅助数组

### 省流版

使用Prim算法求解最小生成树。从节点0开始，每次选择到已选集合距离最小的节点加入，并更新其他节点的距离。循环N-1次即可得到最小生成树的总权值。

## 代码实现

![AC截图](./P1546AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>
#include <queue>
#include <stack>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int ditu[110][110];
int smalltree[110];

int find_small(int n){
    int dp = 0;
    int min = 0x7FFFFFFF;

    for(int i = 0; i<n; i++){
        if(smalltree[i] == 0){
            continue;
        }
        if(smalltree[i] < min){
            min = smalltree[i];
            dp = i;
        }
    }

    return dp;
}

int main(){
    memset(smalltree, 0x7F, sizeof(smalltree));

    int n;
    int chang = 0;
    int nextpo;

    scanf("%d", &n);
    for(int i = 0; i < n; i++){
        for(int j = 0; j < n; j++){
            scanf("%d", &ditu[i][j]);
        }
    }
    for(int i = 0; i<n; i++){
        smalltree[i] = ditu[0][i];
    }

    for(int j = 1; j < n; j++){
        nextpo = find_small(n);
        chang += smalltree[nextpo];
        smalltree[nextpo] = 0;
        for(int i = 0; i < n; i++){
            if(smalltree[i] > ditu[nextpo][i]){
                smalltree[i] = ditu[nextpo][i];
            }
        }    
    }


    printf("%d\n", chang);
    
}
```
