# P1434 [SHOI2002] 滑雪

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P1434

知识点：动态规划、记忆化搜索

## 题目简述

> 给定一个 R×C 的二维高度矩阵，每个格子有一个高度值。一个人可以从某个点滑向上下左右相邻四个点之一，当且仅当目标点的高度严格小于当前点。求区域中最长滑坡的长度。
>
> 数据范围：1 ≤ R, C ≤ 100，0 ≤ h ≤ 10000。
>
> 时间限制：1S，空间限制：125MB。

## 题目分析

### 详细版

**1. 读题**

题目要求的是网格中从任意起点出发、每次只能移动到相邻更低格子的最长路径长度。路径可以任意长，但受限于网格大小和高度递减约束。

**2. 性质观察**

对于任意一个格子 `(x, y)`，从它出发的最长滑坡只依赖于它四周比它低的那些格子。换句话说，如果我们已经知道了所有更低邻居的最长滑坡长度，那么从 `(x, y)` 出发的最长长度就是：

```
f[x][y] = max(f[nx][ny]) + 1
```

其中 `(nx, ny)` 是 `(x, y)` 四周高度更小的相邻格子。这种“大问题分解为已解决的子问题”的结构，正是动态规划的核心。

**3. 数据结构与算法选择**

使用二维数组 `ditu[x][y]` 存储高度，`f[x][y]` 存储从 `(x, y)` 出发的最长滑坡长度。由于状态之间的依赖关系由高度决定，并不是简单的线性递推，因此采用**记忆化搜索**实现最为直观：递归计算每个格子的 `f[x][y]`，计算过就直接返回，避免重复。

**4. 程序设计**

- 输入矩阵大小和高度。
- 对每个格子调用 `dfs(x, y)`。
- `dfs(x, y)` 中，若 `f[x][y]` 已经计算过则直接返回。
- 否则初始化 `f[x][y] = 1`（至少包含自身）。
- 枚举上下左右四个方向，若相邻格子在边界内且高度更小，则递归计算 `dfs(nx, ny)`，并更新 `f[x][y]`。
- 最终答案为所有 `f[x][y]` 的最大值。

**5. 时空复杂度分析**

时间复杂度：每个格子最多被计算一次，每次计算枚举 4 个方向，因此为 O(RC)。
空间复杂度：需要两个 R×C 的数组以及递归栈，均为 O(RC)。

### 省流版

对每个格子记忆化搜索，向四周更低的格子转移，取最大值加一即为当前格子的最长滑坡长度，遍历所有格子求最大即可。

## 代码实现

![AC截图](./P1434AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stack>
#include <string>
#include <queue>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int ditu[110][110];
int f[110][110];
int r, c;
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

int dfs(int x, int y){
	if(f[x][y] != 0) return f[x][y];
	f[x][y] = 1;
	for(int i = 0; i < 4; i++){
		int nx = x + dx[i];
		int ny = y + dy[i];
		if(nx >= 0 && nx < r && ny >= 0 && ny < c && ditu[nx][ny] < ditu[x][y]){
			int t = dfs(nx, ny) + 1;
			if(t > f[x][y]) f[x][y] = t;
		}
	}
	return f[x][y];
}

int main(){
	scanf("%d%d", &r, &c);
	for(int i = 0; i < r; i++){
		for(int j = 0; j < c; j++){
			scanf("%d", &ditu[i][j]);
		}
	}

	int ans = 0;
	for(int i = 0; i < r; i++){
		for(int j = 0; j < c; j++){
			int t = dfs(i, j);
			if(t > ans) ans = t;
		}
	}

	printf("%d\n", ans);
}
```
