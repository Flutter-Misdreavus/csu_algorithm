# P5019 [NOIP 2018 提高组] 铺设道路

## 题目信息

题目链接：https://www.luogu.com.cn/problem/P5019

知识点：贪心、差分思想

## 题目简述

> 一条道路由 $n$ 块连续区域组成，第 $i$ 块下陷深度为 $d_i$。每天可选一段连续区间 $[L,R]$，将区间内每块区域的下陷深度各减 $1$（要求操作时区间内每块深度均 $>0$）。求把所有区域填平（深度全为 $0$）所需的最少天数。
>
> 数据范围：$1\le n\le 10^5$，$0\le d_i\le 10^4$。
>
> 时间限制：1S，空间限制：128MB。

## 题目分析

### 详细版

**1. 读题**

每天能把一段连续区间整体「下降」$1$。要把整个高度数组削平到 $0$，求最少操作天数。

**2. 性质观察**

**关键贪心结论**：从左到右考虑，答案 = $d_1 + \sum_{i=2}^{n}\max(0,\,d_i-d_{i-1})$。

直观理解：相邻两块比较，

- 若 $d_i > d_{i-1}$，高出的部分 $d_i-d_{i-1}$ 必须用新的操作来填，无法蹭到左边的区间；累加这部分增量；
- 若 $d_i \le d_{i-1}$，当前这一块可以「搭便车」——填左边时顺带把它也填了，不需要新增天数。

这正是「正差分之和」，等价于把高度折线中所有**上升沿**的高度累加起来。

**3. 数据结构与算法选择**

无需存储整个数组，只需在线读入：维护前一块高度 `hight`，逐块累加上升量。

**4. 程序设计**

1. `day=0, hight=0`；
2. 逐块读入 `road`：若 `road > hight`，则 `day += road - hight`；
3. 更新 `hight = road`；
4. 输出 `day`。

（初始 `hight=0` 自然处理了第一块的全部高度 $d_1$。）

**5. 时空复杂度分析**

单次线性扫描，时间复杂度 $O(n)$，空间 $O(1)$。$n\le 10^5$ 可以通过。

### 省流版

贪心 / 差分。答案等于高度折线所有上升沿之和：从左到右，只要当前块比前一块高，就把高出的部分累加到天数；不高于则可蹭前面的操作。即 $d_1+\sum\max(0,d_i-d_{i-1})$。时间复杂度 $O(n)$，空间 $O(1)$。

## 代码实现

![AC截图](./P5019AC.png)

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>
#include <list>
#include <map>
#include <set>
#include <queue>
#include <stack>
#include <string>
#include <algorithm>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>

using namespace std;

int main(){
	int n;
	int day = 0;
	int road;
	int hight = 0;

	scanf("%d", &n);
	for(int i = 0; i < n; i++){
		scanf("%d", &road);
		if(road > hight){
			day += road - hight;
		}
		hight = road;
	}

	printf("%d\n", day);
}
```
